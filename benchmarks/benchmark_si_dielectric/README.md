# Si k4 impulse-only dielectric comparison

Stage 1 of the approved Si comparison: PBE (`libxc_pbe`), HSE06, PBE0 and
PBEh(40), eight-atom diamond conventional cell, a=10.26 bohr, 16^3 real-space
mesh and full 4^3 k mesh. All hybrid production runs use the common distributed
full-support EXX path. No rVV10, zero-field trajectory or current subtraction.

```sh
python3 benchmarks/benchmark_si_dielectric/test_workflow.py -v
python3 -u benchmarks/benchmark_si_dielectric/run.py \
  --root /absolute/path/to/results --exe /absolute/path/to/salmon --phase preflight
```

MPI4/OMP1/BLAS1, one calculation at a time. Run after other heavy calculations
finish for meaningful timing. `preflight` converges each GS, runs impulse probes
at dt=.08 and .04 au over 1.28 au, and checks current agreement, energy drift
and electron norm. A failed calculation or check stops the queue. No fixed-time
budget substitutes for convergence. All files from a failed run are retained.

`--phase prepare` writes reviewable inputs without running; `--phase production`
requires successful preflight records and starts 4375 steps at dt=.08 au
(T=350 au, nominal 0.4885 eV spacing). `--phase all` does both in sequence.
Use `--functionals pbe hse06` to select a subset. Do not run two instances against
the same output directory. The script will not overwrite an existing failed run;
move it to a named archive before retrying.

The binary is copied to the result directory and checked by SHA256. Use this
snapshot for later phases (`--exe /absolute/path/to/results/salmon`) even if the
main development binary changes. Input hashes, exit status, GS convergence and
RT row count are checked. `active.json` records the currently launched MPI PID;
per-run `status.json` records completion, wall time, and per-rank peak RSS.
The sum of rank peaks is not a simultaneously measured total. Report full-run
wall/step as including initialization; use SALMON's RT-loop timers for propagation
cost when comparing implementations.

PBE0/PBEh default Coulomb radius is 20.52 bohr for this k mesh. It is not the
MLWF support radius. The later 4x1x1 Gamma comparison has a different default
Coulomb radius (5.13 bohr); do not interpret cross-stage differences as only DC
error. The matching ordinary Gamma reference and DC buffer/local-support checks
are a separate stage, not generated by this stage-1 runner.
