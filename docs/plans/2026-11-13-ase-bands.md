# ASE band bridge implementation plan

User-approved scope: ASE Atoms + exact BandPath → existing independent GS runner
→ ASE BandStructure. No energy/forces Calculator or implicit SCF computation.

1. Add an immutable explicit fractional k-point list alongside segmented BandPath.
   Native optional &band/file_band_kpoints reads the exact list and pads only the
   final point; retain the legacy segmented branch and solver update order.
2. Optional salmonpy.ase module uses ASE and f90nml only when invoked. Load Atoms
   from the original GS input (not native binary provenance inference). Check cell,
   ordered species and positions against user Atoms and path.cell before running.
3. Preserve all ASE k points, labels, path separators and cell in saved ASE JSON.
   Convert (k,band,spin) Hartree to (spin,k,band) eV; require explicit reference_ev.
   Do not infer Fermi level or change primitive/conventional cell.
4. Test nonorthogonal bases, mismatches, disconnected paths, exact native k list,
   immutable caller inputs, energy axis/unit conversion and optional dependencies.
5. Real existing Si GS: disconnected ASE path, compare shared points/direct native
   results, verify source hashes, render ASE plot. Update separate human guide and
   AI JSON, package optional extra and verify installed wheel.
