# WSe₂ SOCを通常の計算経路へ接続する実装計画

**Goal:** 単層WSe₂を最初の対象に、SOCを失わずに擬ポテンシャル、GS、バンド、A駆動TDDFT、電流、MPI、複数状態、保存／再開を使う。

**Architecture:** 同梱FortranのSOC演算を利用し、Pythonが明示するモデル条件を状態の識別と保存形式まで維持する。スカラー相対論版への自動置換やSOC出力をスピン独立2系とみなす実装は追加しない。PBEを最初の実証条件とし、他XCは個別の検証範囲として管理する。

**Tech Stack:** Fortran/C、既存Python API、NC-UPF、Libxc、MPI。

## 1. 完全相対論擬ポテンシャルと入力

- PseudoDojo公式PBE v0.4 FR standardを固定コミット・SHA256・CC-BY-4.0・出典付きで選択する。Wは14価電子、Seは16価電子、WSe₂は46電子。
- スカラー版とFR版を別のIDにし、元素だけで選択しない。取得と計算可能な範囲を区別する。
- k点はSALMON本体の標準分割を使う。Pythonは `num_kgrid=2,2,1` を渡し、SOCを理由にシフト・Γ中心指定・独自の点列を追加しない。
- `Pseudopotential` はSOC情報を保持し、`DFT(spin_orbit=True)` が `spin=noncollinear, yn_spinorbit=y` を出す。状態数は電子数以上のスピノル本数とする。
- 明示した参照情報をGS結果に保存する。物理的な再開互換性はファイルハッシュと計算条件で判定し、出典表記の違いだけで計算を拒否しない。

## 2. 既存演算と状態所有の分離

- `src/so/noncollinear_module.f90` の `den_mat`, `vxc_mat`, `old_mat`, `rot_ang`, `dmat_old` を状態の保持・切替・複製の対象にする。単に入力拒否を消す変更はしない。
- `src/gs/main_dft.f90` のSCF状態、`src/rt/embedded_tddft.f90` のモデル・状態切替に接続する。異なるSOC入力とスカラー入力を交互に呼んで独立実行と一致させる。
- 電子数・占有数・電流のスピノル規約を `occupation.f90`, `density_matrix.f90` と照合する。2成分を独立したスピンチャンネルとして二重集計しない。

## 3. 通常の入口

- DFT・ASE・バンド・GSからTDDFTへの変換・別プロセス／共有モデル／登録モデルに同じSOC設定を通す。
- `tddft_worker.f90`, `embedded_tddft.f90`, `_shared_tddft.py`, `_hse_assets.py`, `bands.py` の制限は実装・検証済みの範囲に合わせて変更する。
- A/c駆動のx/y/z・円偏光を保持し、SOCを無視する代替を入れない。初期標準はtransverse、固定イオン。

## 4. 保存・再開

- SCF混合履歴・スピン密度行列・XC行列・スピノル波動関数・占有数・直前Aを直接保存する。
- メモリ復元、ディスク復元、プロセス終了後の再開、保護付き候補、MPI分割変更へ展開する。再計算で状態を作り直す方法を直接復元として扱わない。
- GS/2のスピノル表現・占有数上限・状態識別を明示的に改訂し、旧形式への自動変換や暗黙の補間はしない。

## 5. WSe₂検証

入力準備は計算開始と分離する。初回は3原子、a=3.28 Å、Seの高さ1.67 Å、zセル20 Å、24×24×128格子、2×2×1 k点、46電子、64状態、Libxc-PBE、4スレッド。これは接続検証用の構造で、実験・収束済みの基準構造ではない。

- 監査済みSALMON直接実行を同じ入力の比較相手にする。SOCバンド分裂の存在だけを正しさの証拠にしない。
- x/yおよび左右円偏光の短い時間発展、実測電子数、物理的電荷電流を比較する。
- 独立状態、通常／性能モード、保存／再開、失敗後再試行、1/2ランクで比較する。
- 正常なスカラーSiの既存結果を維持する。格子・k点・真空・dt・物理時間の収束は接続試験と別に報告する。
- 実GS・ログ・再開データの保存は作業ルールに従い許可を得る。新規ビルドはソース／全アプリケーションオブジェクトの禁止固有値ソルバー監査を維持。重い物理検証CIは追加しない。

## CIの小規模材料：Ni（ユーザー指定）

- SOCの小規模CI候補をfcc Niとする。単一元素の小さなセルで、磁性・スピノル・金属の占有数を扱う入口を確認する。非磁性のWSe₂の実用途検証とは相補的に使う。
- 完全相対論NC-UPF（3s/3pセミコア・18電子）、乱数シード0のスピノル初期化、占有数／温度の指定を整えた。磁化ベクトルを直接指定する入口は今後の作業。単に `spin_orbit=True` にするだけで強磁性基底状態を保証しない。
- 毎pushの検査は入力・ABI・有限値・独立状態・SCF途中保存／再開など短い契約検査に絞る。未収束を意図した短いSCFはその状態を検査して終了し、無断でRTへ進まない。
- RT検査が必要なら事前に検証したGSを明示的に供給する。磁気モーメント、異方性、バンド分裂、光学スペクトルの収束・再現は手動の実材料検証とし、毎push CIに追加しない。
- k点はSALMON本体の標準分割を用い、NiのCI用はユーザー指定（2026-11-23）の2×2×2（全8点）とする。WSe₂は引き続き2×2×1。いずれも物性の収束保証ではない。
- 既存CIと統合し、新たな重複ビルドや遠隔Actionsの追加実行は行わない。Niの短いSOC・セミコア検査は実装・ローカル1/2スレッド検証済み。既存の手動CIに組込み済みで、遠隔実行は未実施。検査範囲は初期化・3回SCF・SOC作業配列の復元で、SCF/TDDFT全体の保存再開とは区別する。
