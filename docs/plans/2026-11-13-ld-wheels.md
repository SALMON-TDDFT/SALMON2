# LD wheel distribution plan

Goal: distribute the unchanged LD kernel and Python API as native wheels.
Architecture: scikit-build-core invokes isolated CMake project; installed files
are explicitly listed. cibuildwheel repairs runtime dependencies and tests the
installed wheel outside checkout. Recompute native hash after relocation.

1. Add packaging tests for native naming and repaired wheel RECORD/hash.
2. Add pyproject and independent CMake target with source/object audits.
3. Add dependency repair and hash refresh tooling, Windows DLL loader support.
4. Add CI for CPython 3.10–3.14: Linux x86_64, Windows AMD64, macOS arm64/x86_64.
5. Locally build sdist then wheel, repair macOS runtime dependencies, install in
   clean venv and run numerical/API tests outside source tree.
6. Document tested versus CI-pending targets. Upload CI artifacts only; no PyPI publication.
