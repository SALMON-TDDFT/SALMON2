# Si の実時間 TDCDFT 試験：設計と実装

状態：ユーザーの「進めましょう」に基づきTDCDFTブランチで実装。短時間の数値検証済み。収束した物理評価は未完了。

## 目的

Si の impulse 線形応答で交換相関ベクトルポテンシャルによる励起子効果を検証し、次にレーザー励起後の光学応答の変化を評価する。

## 採用候補

初期実装は ALDA のスカラーポテンシャルに head-only LRC ベクトルポテンシャルを追加する。局所スカラーポテンシャルは変更せず、文献の LRC+ における beta=1 に相当する。alpha は固定の入力パラメータとし、初期比較は 0, 0.1, 0.2, 0.3。0.2 は文献値を用いた開始点で、SALMON の擬ポテンシャル・格子・基底条件での最適値を保証しない。

参照：Sun et al., Phys. Rev. Lett. 127, 077401 (2021), https://doi.org/10.1103/PhysRevLett.127.077401 。文献の粒子電流 j に対して d²Axc/dt²=alpha*j。SALMON の電流の符号、A/c の単位、非局所擬ポテンシャル電流を追跡し、実装式と入力 alpha の定義を確定する。式を転記するだけで符号を決めない。

## 実装範囲

- 周期的バルク Si、固定イオン、非スピン偏極、横応答 trans_longi='tr'、通常の実空間 RT 経路。
- 初期伝播法は middlepoint。未検証の aetrs、Maxwell 結合、MD、その他非対応経路は新機能が有効なとき明示的に拒否する。
- s_rt に Axc の履歴を保持し、古典電磁場 Ac_ext/Ac_ind/Ac_tot とは独立に管理する。
- 波動関数伝播・物理電流・非局所擬ポテンシャルの位相で、一貫した有効ベクトルポテンシャルを使う。
- Axc、対応する Exc、必要な履歴を出力・再開できるようにする。無効時には既存の結果と再開形式を維持する。
- 入力は既定で無効。入力値の検証、MPI broadcast、variables.log への記録、SALMON-DOCS の説明を含める。

## 第１段階：impulse 線形応答

既存の samples/exercise_04_bulkSi_gs と exercise_05_bulkSi_lr を出発点とし、同じ基底状態・擬ポテンシャルで ALDA と ALDA+LRC を比較する。

評価量は Im epsilon、E1/E2 の位置・高さ・指定エネルギー区間の積分強度。Si の連続体励起子による吸収構造の変化を評価し、E1 ピーク位置を束縛エネルギーと解釈しない。バンドギャップ誤差と励起子補正を分離し、表示のエネルギーシフトを使う場合は未シフト値も保存する。

必須確認：alpha=0 の既存結果再現、impulse 振幅を半分にした規格化応答の一致、dt/2、k 点・実空間格子・伝播時間の収束。全比較で同じ窓関数・ブロードニングを使う。既存の粗いサンプル設定は動作確認用であり、定量評価の収束条件とはしない。

## 第２段階：レーザー励起後の応答

ポンプのみ、および同じポンプに遅延した弱い impulse を加えた計算を行う。可能なら正負プローブの中心差分を使い、プローブ振幅依存性も確認する。

delta J(t;tau) = J_pump+probe(t;tau) - J_pump(t)

をプローブ時刻を原点にフーリエ変換し、プローブ電場に対する応答を求める。ポンプ電流そのもののスペクトルを励起後の吸収と同一視しない。有限観測窓で定義する非平衡応答として、観測窓・遅延・偏光を明記する。

SALMON の ae_shape2='impulse' を利用できるが、T1_T2 はパルス中心等との関係を実装から確認して設定する。ポンプのみとプローブ付きで共通の初期状態・時間軸・窓を使用する。

ポンプ条件の開始候補は文献の 1.6 eV、10 fs を参考にする。ただし SALMON の envelope と tw1 の意味を文献のパルス定義に合わせる。強度・遅延・偏光は線形応答検証後に決める。まずポンプなし極限で第１段階の結果を再現する。

固定 alpha では励起キャリアによる遮蔽の変化を自己無撞着に表現しない。得られるピーク変化はこのモデル内での予測であり、励起子の解離や密度依存遮蔽を定量的に検証したことにはならない。強励起の前に時間刻み・電流・Axc の安定性を確認する。

## 完了条件

機能実装の完了と物理評価の完了を区別する。前者は標準 Fortran ビルド、無効時回帰、alpha=0、履歴更新の単体検証、MPI と再開の代表例で判定する。後者は収束した Si スペクトル、パラメータ比較、文献等との比較、ポンプ・プローブ差分の検証と限界の記録が必要。


## 確定した規約と離散化

SALMONの `system%vec_Ac` はA/c、`calc_current` は正の電子数電流を返す。
したがって実装式は `a''+beta*a'+gamma*a=+alpha*j`。スカラーポテンシャルはPZのまま。
Proca型安定化も選択可能にしたが、係数の自動フィットは実装していない。
Dewhurst論文のHamiltonianのAの符号をSALMONに合わせると
`alpha=-4*pi/a2`, `gamma=a0/a2`（原子単位、体積平均電流）の対応になる。
この対応は同論文の非線形結果の再現を保証するものではない。

中心差分は
`a[n+1]=((2-gamma*dt²)*a[n]-(1-beta*dt/2)*a[n-1]+alpha*dt²*j[n])/(1+beta*dt/2)`。
新規計算はa[0]=a'[0]=0、a[1]=alpha*j[0+]*dt²/2で開始する。
初期電流は外場のキックを含む端点場で計算する。再開時は保存した2時刻を使用する。
波動関数は中点の有効A、電流は端点の有効Aと非局所位相で評価する。
alpha=0でもXC有効経路内で端点位相を更新し、レーザーのゼロ結合極限を連続にする。
古典場が一定のimpulseでは従来結果との一致を確認した。
レーザーでは従来の中点非局所位相と異なるため、XC有効alpha=0を比較基準とする。

入力条件、例、解析法、既知の限界は `samples/exercise_si_tdcdft/README.md` を参照。
