# PBEh(40)+rVV10 water dynamics implementation plan

**Goal:** Add PBEh(40)+rVV10 through the inherited MLWF/ACE exchange path, with a tested fixed-cell Born–Oppenheimer MD entry point.

**Architecture:** Preserve MLWF gauge transport, occupation weighting and ACE. Extend its FFT pair-density kernel to spherical-cutoff unscreened Coulomb, with an explicit radius and the finite analytic G=0 limit (converge radius and supercell together). Use 0.4 exact exchange and 0.6 PBE exchange plus full PBE correlation. Add periodic rVV10 via spline channel FFT convolution and the analytic Fourier transform of its rational kernel. Differentiate the same interpolated functional, then use SALMON's existing adjoint gradient/divergence and fixed-grid ionic force path.

**Tech Stack:** Fortran, FFTW, Libxc C ABI, BLAS, MPI, Python/NumPy/SciPy fixtures.

## Accepted scope and decisions

- Base: origin/dc-hse-mlwf-ace at 4048d67f. New branch pbeh40-rvv10-water-md, separate sibling worktree; existing TDCDFT changes untouched.
- User explicitly requires inheriting MLWF localization and ACE, not substituting a separate dense exchange backend.
- Functional names: pbeh40, pbeh40_rvv10. Inputs: pbeh_coulomb_radius (input length, 0 means half shortest Born–von Karman supercell length), rvv10_b=5.3, rvv10_c=0.0093, rvv10_nq=32.
- The finite-range Coulomb convention is a controlled periodic approximation, not HSE screening. No orbital/pair pruning is silently enabled. Full-support MLWF remains the reference.
- First MD scope: unpolarized orthorhombic fixed-cell conventional BOMD, no NLCC. Reject DC MD, RT, ionic optimization and unsupported combinations rather than silently using uncertified forces. Conventional static pbeh40_rvv10 uses the same MLWF path as fragment exchange.
- DC rVV10 needs total-system density convolution (not fragment-additive dispersion); do not claim support until that is integrated and checked.
- No push or merge requested.
