# TB-mBJ worker validation

Extend the already validated A-driven worker allowlist to native `tbmbj` only.
Keep native automatic predictor-corrector dispatch, current-dependent kinetic
energy density, automatic/fixed cval and all numerical update order unchanged.
Test rejection before the change, then ordinary pre/post output equality and
worker equivalence for both automatic and fixed cval, independent states and
recovery. Run a newly converged Si GS followed by RT and independent-state tests.
Document the model-potential energy limitation and tested pseudopotential.
Dependency distribution is a design proposal only: no import-time builds or
new installer API in this change.
