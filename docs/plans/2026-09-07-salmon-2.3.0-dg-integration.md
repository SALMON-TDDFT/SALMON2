# SALMON 2.3.0 DG Integration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Produce a separately named DG development branch based on the authenticated official SALMON `v.2.3.0` tag while preserving the current DG branch, dirty worktree, and calculation logs.

**Architecture:** Authenticate the official release and supplied archive first, capture the dirty DG state through an isolated Git index, then perform a true three-way merge in a temporary ordinary clone. Resolve shared SALMON/DG entry points explicitly, verify conventional SALMON and DG behavior in stages, and import only the tested integration branch back into the original repository.

**Tech Stack:** Git tags/trees/temporary indexes, CMake Release builds, GNU Fortran, MPI, ScaLAPACK, Wannier90, Python contract runners, SALMON GS/RT sample calculations.
