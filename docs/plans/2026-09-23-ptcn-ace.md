# PT-CN-ACE implementation plan

Goal: implement parallel-transport Crank–Nicolson (Jia/Lin arXiv:1809.09609, Eq.12) and measure time-step/accuracy/cost in the existing independent HSE Si driver.

Architecture: row-stored orbitals, F(U)=H[U]U-U(U†H[U]U). Solve V+i dt F(V)/2=U-i dt F(U)/2. Initial endpoint action is exact; accepted endpoint full action is reused for the next step. ACE accelerates inner iterations only. Fresh untruncated exchange certifies every accepted endpoint residual. No orthonormalization inside or after the solve; record endpoint Gram drift because nonlinear trapezoidal PT is not assumed exactly norm preserving. Existing original-gauge midpoint and RK4 remain unchanged.
