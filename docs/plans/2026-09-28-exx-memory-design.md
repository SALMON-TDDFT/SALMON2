# Native EXX memory reduction — approved design

User approved two phases on2026-09-28: eliminate redundant buffers, then store local-support exchange without expanding dense ACE factors. Preserve real-space mesh propagation, all existing support radii/norm thresholds, HSE/PBEh semantics, and no memory cap.

Phase1: apply midpoint ACE as half the sum of endpoint operators, retaining two endpoint states but eliminating the concatenated double-width factors. Add exchange action directly to mesh hpsi, removing output_work. Cache exchange action only for DC core energies; preserve exact refresh equality checks. Avoid unnecessary refresh temporaries and transfer ownership where possible. At128 H2/MPI16 each mesh-by-occupied complex array is64MiB;256MiB/rank is the capacity of the first identified redundant buffers, not a promised RSS reduction.

Phase2: for source-support ACE store sparse unwhitened W=K_S S plus the small metric inverse M^-1, where M=-S^H W dv. Apply K_ACE=-W M^-1 W^H dv. This is algebraically the same operator as dense whitened factors. Pack only exact nonzeros, never threshold numerical values. Preserve Hermitian/positive/conditioning checks. Stream target columns across orbital owners; spatial/orbital reductions construct overlaps and actions without gathering full wavefunctions. Masked source arrays need not survive a fixed-ion source-ACE refresh: subsequent refresh regenerates them; the untruncated transported gauge state remains. Dense occupied-vector fallback remains valid.

Native RT wavefunctions and untruncated gauge-transport data remain dense. Small metric matrices remain O(Norb^2), so total memory is not claimed linear. Stage1 and sparse representation must be tested independently against dense reference, including complex nonorthogonal vectors, zeros, failed builds, empty and uneven orbital owners. Verify native HSE/PBEh16-step currents/energies and8/64/128H2 RSS/time using existing source-ACE data; no Full remeasurement. Keep strong scaling on hold.
