# Point-Cogroup Joint Center Gauge Design

## Evidence and rejected approach

The first periodic-position implementation removed the crash and the accidental
`O(Ngrid^2)` fingerprint, but it did not repair the affine center orbit.  On
Si64 it completed the factored point-cogroup proof with closure defect
`2.20e-12`, then failed operation 2 with center residual `6.25e-2`, monomial
defect `7.46e-1`, and center-block leakage `1`.  The earlier fixed irrational
linear combination of the three position matrices is therefore rejected: a
fixed Cartesian direction is not invariant under the point cogroup.

## Chosen construction

For one translation-character sector form the six Hermitian matrices

```text
H_(a,+) = (Z_a + Z_a^H)/2,
H_(a,-) = (Z_a - Z_a^H)/(2i),  a=1,2,3.
```

Find one unitary `U` that jointly approximately diagonalizes all six matrices
by minimizing

```text
J(U) = sum_q ||offdiag(U^H H_q U)||_F^2.
```

`J` is unchanged by an orthogonal transformation among the Cartesian
components, so the minimizer set is point-cogroup covariant.  Use bounded
complex Jacobi sweeps on the small internal multiplicity (`m=12` for Si64).
Every two-column update solves the exact local 2x2 minimization.  Stop only
when the maximum update and objective decrease are collectively below the
declared tolerance; otherwise reject.

To avoid a seed-dependent local minimum, use a deterministic multistart set
generated from the point-cogroup orbit of one coefficient vector plus the
LCFO operator.  Evaluate the invariant objective for every start, select the
strictly smallest objective, and resolve tolerance ties by the sorted periodic
center tuple and then the full center-block projector stream.  The start set
is closed under the supplied integer point rotations, so input point rotation
only permutes candidates.

## Degeneracy and transport

After joint diagonalization, group columns whose three periodic centers agree
within tolerance.  Use the projected LCFO physical operator only inside each
repeated-center block.  A nondegenerate LCFO spectrum fixes the internal
channels.  An exactly degenerate LCFO block is a physical multiplet: retain
its projector, do not use LAPACK's arbitrary columns as canonical metadata,
and transport one common block gauge through the measured point intertwiner.

Point-character orbits are processed exactly once.  A reference sector is
jointly localized; target sectors receive its gauge through the existing
finite-group intertwining phase and point representation.  Non-self-conjugate
partners are generated by Gamma sewing, while self-conjugate sectors use the
existing fixed-real branch.  The inverse character accumulator receives each
result once.

## Data flow and memory

Production materializes only one spatial sector (and one conjugate partner),
builds its weighted position tuple, and stores six `m x m` matrices plus a few
`m x m` rotations.  Jacobi candidates are reused in place.  No all-sector
tensor, replicated retained-rank matrix, `Ngrid x T` action, or full spatial
projector is introduced.  Fingerprints stream global rows once, giving
`O(Ngrid*m)` communication rather than `O(Ngrid^2)`.

## Collective safety and receipts

Before any shape-dependent branch, agree dimensions, tolerance, catalog and
point metadata, tuple payload, LCFO payload, and candidate count.  Preflight
all default-integer, MPI-count, and byte arithmetic with checked `int64`.
Allocation failures, LAPACK/Jacobi convergence decisions, cluster boundaries,
and candidate selection are reduced collectively before returning.

Publish the initial/final joint objective, maximum Jacobi update, sweep count,
center-block multiplicities, position covariance defect, Gamma defect,
workspace peak, and a fingerprint binding the catalog, weighted tuple, LCFO
operator, sorted centers, exact-multiplet projectors, and final row-owned
sector.

## Acceptance

Focused MPI tests must distinguish the directed Z4 action, preserve a Z2xZ2
self-conjugate real frame, recover two mixed distinct centers, preserve an
arbitrary rotation in an exact coincident-center multiplet, reject a split or
nonconverged block, and return identical receipts on 1/2/4/8 ranks.  Si64 must
pass the unchanged center gate; tolerance relaxation is not an acceptance
path.
