# SAWF DMN Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Generate validated Wannier90 `.dmn` symmetry representations for the Gamma-only DC-LCFO pseudo-channel workflow and activate `site_symmetry` safely.

**Architecture:** Add an optional spglib backend and a `sym.dat` backend behind one normalized symmetry-operation type. Build `D_wann` from complete real s+p+d shells and `D_band` from distributed real-space LCFO overlaps in a new SAWF module, validate both representations, then write `.dmn` before enabling Wannier90 SAWF.

**Tech Stack:** Fortran 2008, C interoperability, CMake, optional spglib, MPI, EigenExa, Wannier90 3.1, Python source and file-format regression tests.
