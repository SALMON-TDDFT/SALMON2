# 交換作用と逆変換のブロック化

前回はpacked ACEを作用する際の対象配列だけをブロック化した。今回はpair screening経路で局在軌道への交換作用を32軌道ずつ計算し、K(WF)U†を逐次加算する。出力wはACE構築に必要なため保持し、全軌道分のlocalized_actionとadjointを除去する。

全ターゲット数をspatial_exx_applyへ任意引数として渡し、対省略の1対当たり閾値を従来と維持。ブロックごとの誤差境界は二乗和、統計とFFT仕事量は和にする。全軌道の分散ゲージ実験経路は既存処理を維持する。

1. ブロック作用と逆変換を実装し、対省略・source ACE回帰を実行。
2. 1軌道の小ブロックでも回帰し、複数ブロックを強制する。
3. 64 H2の保存GS、occupied ACE、pair diagnose（逆変換を通る）で前後16ステップを各1回。
4. 電流・エネルギー、対数・誤差境界、時間・RSSを比較。source ACEの前回結果を異なる経路の速度比較には流用しない。

## 結果

数値試験は合格したが、64 H2ではRSS削減なし・時間約4.4%増。通常経路への採用は保留し、比較用ビルドでのみ有効化する。実装と測定結果は[ノート](../exx-inverse-blocks-ja.md)に保存。
