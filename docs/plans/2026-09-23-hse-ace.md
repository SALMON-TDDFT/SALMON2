# HSE ACE implementation plan

**Goal:** Build ACE from MLWF full exchange and measure accuracy and actual RT savings on the existing Si reference.
**Architecture:** Per-k low-rank negative Hermitian exchange with grid-weighted products. Reproduce occupied construction action and preserve arbitrary-target linearity. First RT integration uses self-consistent implicit midpoint in the original Bloch gauge; PT gauge/CN is a subsequent extension, not claimed here. Inner iterations update local terms while reusing ACE; outer iterations rebuild full exchange and accept only after checking the full nonlinear midpoint residual. MLWF localization cadence is independent of ACE rebuilding.
**Tech stack:** Existing independent Python/NumPy/FFTW/Libxc HSE reference, no native hybrid changes.

1. Add failing ACE tests for occupied interpolation, Hermiticity/negative sign, complex gauge covariance, invalid or singular input. Implement `ace.py` and run tests.
2. Separate exact exchange action in `scf.py`; preserve existing HSE energy derivative tests. Add failing midpoint tests for linear Cayley solution, nonlinear full residual, and failure gates, then implement `ace_rt.py`.
3. Benchmark real Si occupied interpolation and repeated ACE application. Compare short impulse midpoint/ACE with saved full RK4 and half-step midpoint; measure builds, inner applications, residuals, norm, current, energy, wall times. Preserve no-truncation reference. Do not launch multi-day runs.
4. Run existing tests, document measured gains and limitations, save checkpoints locally and commit code/results. No spectral or long-time stability claim.

User approved MLWF+ACE and short-reference verification by requesting to proceed. Continue directly in the existing TDCDFT branch.

## Implementation outcome

ACE interpolation, negative Hermitian action and complex gauge tests pass. The implicit-midpoint driver has an independently reviewed full-exchange residual gate and accepts a previous-step ACE only as an initial operator. Real Si interpolation error is 1.95e-15. First-step full builds=3; seeded later steps full builds=2, measured ~24.3 s/step vs prior RK4 ~46 s/step at the same dt, with different time-discretization order explicitly retained in reporting. Half-step comparison gives the expected approximately fourfold decrease in short-pilot current error. PT gauge and long-time spectra remain later work, not part of the achieved claims.
