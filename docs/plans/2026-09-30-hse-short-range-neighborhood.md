# HSE short-range neighborhood convolution

Approved design: combine retained-norm WF support with an independent HSE cutoff chosen from erfc(omega R)=hse_sr_tolerance. Default zero disables the approximation. CPU Gamma fixed-ion source-support ACE only initially. Use the existing discrete kernel, report omitted L1/L2 norms, preserve Cartesian ownership. Each rank gathers density only from intersecting neighborhood ranks into an overlap-save FFT window and keeps its own output block. Periodic axes use the original length. Full-window cases retain the original uncut route. Existing ACE validity checks remain mandatory; failed approximate ACE uses uncut occupied-vector fallback.

Implementation/verification steps: (1) input defaults, broadcast, logging and guards; (2) finite-range kernel/window lifecycle; (3) neighborhood exchange and cropped convolution; (4) direct complex-kernel periodic reference under multiple MPI decompositions and unchanged-route regressions; (5) short Si comparison and documented limitations. No changes to running production binaries. No GPU performance claims. The epsilon is a continuum envelope criterion, not an exchange-energy error guarantee.
