# 擬ポテンシャル取得とSi入門の更新（2026-11-23）

## 契約

過去の決定#4に従い、利用者が明示的に許可した場合だけ擬ポテンシャルを取得する。固定Si参照と自作参照は同じAPIで処理し、HTTPS・既知のSHA256・ライセンス・出典・新規保存先を要求する。計算やimportから暗黙に呼ばない。GS/2の参照保存方式は変えない。

Si例は既存入力・期待値・許容差を変えず、現行の電子数付き応答を返す計算プログラムで確認する。旧ZIPは現在の許可一覧から外すが、ハッシュ・出典を歴史情報として残す。検査を外したり旧形式を受け付ける分岐を追加しない。

## 実装と検証

- `salmonpy.pseudopotentials`：参照型、固定Si参照、明示的な取得API/CLI。取得失敗は一時ファイルを除去し、照合前のファイルを計算用保存先に出さない。
- 不許可・既存保存先・SHA不一致・HTTP転送・サイズ超過・不正参照の検査。固定Siデータを実際に取得して同梱データと照合。
- 現行ソースと全アプリケーションオブジェクトの禁止固有値ソルバー監査を保持したビルド。OpenBLAS・Libxcとライセンスを含む再配置ZIPを作成。
- 許可されたGSを1回実行。PZ・54反復、エネルギーと全21時刻の電流が従来期待値と差ゼロ。
- wheelを別環境に導入し、保存済みGSから電流を再計算。追加SCFなしでソース実行とビット一致。wheelの取得APIも実通信で確認。
- 日英ガイド・AI用JSON・現在の残作業一覧を同期。数値演算は既存Fortran側を使用。

新しい配布物はApple Silicon Macでのローカル確認であり、公開Releaseや他OS版の検証は未完。短い固定入力の一致は物理的な収束を意味しない。遠隔CIや重い物理量CIは実行しない。
