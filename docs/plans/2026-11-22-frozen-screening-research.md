# 凍結背景・固有状態射影を使わない遮蔽応答の検討

Status: design approved; numerical core and opt-in single-q diagnostics implemented.
General production W updates remain unvalidated by this diagnostic.
2026-11-22。従来の周期的W更新の計時はユーザー指示で停止した。

## 対象と固定するもの

各更新時刻 t0 の占有RT軌道、A、TB-mBJ局所ポテンシャル、非局所擬ポテンシャル、
HSEX演算子をスナップショットとして保持する。主RT軌道は4本のままで、
補助固有状態への射影・対角占有への置換を必須にしない方式を調べる。
遮蔽の近似はまずRPAとし、誘導TB-mBJ/誘導HSEXの頂点補正を混ぜない。

「Hを凍結する」と「密度行列が定常である」は同じではない。
rho0=sum_i f_i |psi_i><psi_i| が H0 と可換とは限らない。
以下の区別を保ち、コヒーレンスを暗黙に消さない。

- 固定H0で占有軌道と応答軌道を伝播する初期時刻t0のインパルス応答。
  rho0は初期条件であり、その後の無摂動基準もH0で伝播する。
- H0とrho0を係数として固定する断熱スナップショットRPA。
  単一周波数でWを構成する局所定常近似を含む。
- 現行の瞬時固有状態に対する対角占有版。
  コヒーレンスを除いた別の基準なので、励起後の結果が必ず一致するとは限らない。

Perfetto et al.のNEQ-BSEでは、応答を観測する時間内で背景がほぼ変化しないという
時間スケール条件を用いる。これは凍結背景を出発点にする根拠であり、
任意の強いコヒーレンスを持つ状態が自動的に定常になるという主張ではない。
https://arxiv.org/abs/1507.01786
https://arxiv.org/abs/1603.00225

## 候補1：実時間の一次応答を検証基準にする

独立粒子応答では背景軌道と微小変化を

    i d psi_i/dt = H0 psi_i
    i d delta_psi_i/dt = H0 delta_psi_i + delta_v_test psi_i

で伝播する。占有数f_iにスピン縮重を含める規約なら、実摂動に対して

    delta_n = 2 Re sum_i f_i psi_i* delta_psi_i

となる。有限qではkとk+qのセクターを結ぶ。複素q成分について単純な2Reを
そのまま使わず、ket/braと+/-qの両寄与を導出して実装する。
励起後の背景に時間反転対称性があるとは仮定しない。

これは空状態の固有軌道を要求しないが、q・試行電位ごとに応答軌道を必要とする。
背景4軌道の伝播は試行電位間で共有できる。まずchi0を求めてから既存のRPA組立を
使い、背景密度が変化する時間領域でHartreeを自己整合する方式と、凍結rho0の
周波数領域RPAを区別する。両者は一般の非定常背景で同一とは限らない。

同じインパルス応答からetaとeta/2を重みの違いで評価できる。
一方、小さいetaでは長時間の応答が必要になる。
exp(-eta*T)=0.01を単純な尾の目安とした値は次のとおり。
これはWの相対誤差1%を保証する収束判定ではない。

| eta [Ha] | 1/eta [fs] | 尾1%のT [fs] |
|---|---:|---:|
| 0.01 | 2.419 | 11.14 |
| 0.005 | 4.838 | 22.28 |
| 0.001 | 24.189 | 111.39 |
| 0.0005 | 48.378 | 222.79 |

したがって、単純な長時間RTをそのまま高速な本番W更新と見なさない。
定常系の時間依存摂動論とSternheimer式の関係はOctopusの導出を参照。
https://octopus-code.org/documentation/15/developers/code_documentation/linear_response/

## 候補2：凍結Liouvillianの周波数応答を低ランクで解く

まず独立粒子の有限q応答に対して

    L_q X_k = H_(k+q) X_k - X_k H_k
    (z - L_q) X_k = S_k
    S_k = V_q rho_k - rho_(k+q) V_q
    z = omega + i eta

を考える。初期密度行列が与えられた固定Hのインパルスchi0については、
時間伝播による解とこのresolventを独立に照合できる。
これは初期時刻t0を固定した応答の一列であり、時間並進不変性の証明ではない。
このchi0から単一周波数のRPA逆行列でWを作る段階では、断熱スナップショットの
意味を明示する。完全な非定常RPAの二時刻Dyson方程式との同一性は主張しない。
物理的なretarded chi0の規約では epsilon=I-v*chi0、W=epsilon^(-1)*v となる。
現行`screen_assemble`の正符号の分極と規格化を変換してから比較する。

rho_k=Psi_k F Psi_k^daggerなら、S_kは最大2*Noccのランクで表せる。
Siの占有4本では初期ランクは最大8で、rhoのNr×Nr密行列は不要である。
X=U C V^daggerに対してL_q XはH_(k+q)UとH_k Vの作用だけで作れる。
実空間のH作用、BLAS、小行列のQR/SVDを利用する候補である。
主RTの表現を別の軌道基底へ変更するものではない。

ただし反復中のXのランクは増える。初期ランク8から、解やKrylovベクトルも
ランク8のままで正確に保持できるとは言えない。圧縮誤差、真の方程式残差、
chi0*x、W*xの誤差を別に測る。多シフトKrylovが使えればetaとeta/2の演算を
共有できるが、ランク切捨て後の再帰・残差は再検証する必要がある。

Liouville-Lanczosは空状態を明示しない線形応答の先行例である。
ただし通常の定常占有空間に対するバッチ表現の閉性を、Hと可換でないRT密度行列へ
そのまま適用してよいとはしない。非平衡有限q・低ランク拡張は今回の検証対象。
https://arxiv.org/abs/0801.1393

## 射影なしで測れる背景の変化

占有軌道を規格直交化したPsi、共通占有数をfとし、rho=f*Psi*Psi^daggerとする。

    Y = H0 Psi - Psi (Psi^dagger H0 Psi)
    ||[H0,rho]||_F^2 = 2 f^2 ||Y||_F^2
    ||rho||_F^2 = f^2 Nocc

から、固定H0のもとで密度行列が変化する速さを、占有4本へのH作用と小行列だけで
調べられる。これは固有状態射影ではなく、占有部分空間内の回転を除いた残差である。
k重み付きノルムはランクごとの寄与をMPI和すればよく、全kのrhoは不要である。
応答の記憶時間に対するこの変化率は、凍結rho近似を診断する目安になる。
実際のポンプによるH自体の変化も別に調べる。単一のノルム閾値でWの精度を保証しない。

## SALMONで流用できる部分と変更が必要な部分

- `src/xc/hsex_internal.f90`の実空間H作用とk索引の扱いが出発点になる。
  Vlocal、A、ppg、HSEXを同じ時刻に固定する。各H作用には凍結HSEXを一度だけ含め、
  グローバルな`projection_action`による二重加算を避ける。
  応答中に`hsex_stage`で主RTの密度やsigmaを更新しない。
- `src/xc/hsex_screen_math.f90`の幾何、有限グリッド形状因子、RPA組立、
  qから実空間Wへの変換を使える可能性がある。
- 現行`sternheimer_band`の`levels/occupations`をRT軌道で単純に置換しない。
  現行ソルバーは固有エネルギーと固有状態の補空間を前提としている。
- 新しいcommutatorのchi0は両向き遷移を既に含む。
  現行の+/-q加算・スピン因子・2/(Nk*Omega)を重ねて二重計上しない。
  密度行列にf=2を含める規約と既存正符号応答の間を導出して照合する。
- k点MPI分散を保ち、k+qから必要な占有軌道のみ交換する。
  rhoや全kの応答を各ランクへ複製する方式を前提にしない。
- コヒーレンスを保持した静的応答が、現行の実数・相反的W形式に適合するかは
  別の検証事項である。ファイル形式だけでなく、Hermitian逆行列、正定な光学誘電率、
  Hermitianな瞬時HSEXという物理・ソルバーの前提も確認する。
  反エルミート成分や非相反成分を黙って捨てない。

## 段階的な検証案

1. 小さい独立模型で、定常密度行列とHと可換でない密度行列の両方を用意する。
   固定Hのインパルス伝播、明示Liouvillian参照、低ランクresolventを比較する。
   電荷保存、一様電位への零応答、スピン係数、+/-q、eta対を検証する。
   密行列は小模型の参照に限り、本番経路では作らない。
   chi0の一致に加え、無摂動rho_bg(t)も伝播するHartree自己整合応答を参照にし、
   単一周波数スナップショットRPAのWとの差を測る。
2. 既存Si小格子の非ゼロq一点で、平衡chi0*xを現行Sternheimerと照合する。
   同じグリッド・クーロン・k重み・eta・試行電位を使う。
   初回は光学head/wingや全qのW構築を同時に変更しない。
3. 弱いポンプのスナップショットで、射影なしのコヒーレント応答と、現行の対角
   占有版の差を測る。差を数値誤差と決めつけず、凍結・脱位相近似の差を切り分ける。
4. ランクと精度を掃引し、基底/圧縮費も含めた時間、H作用回数、MPI通信量、
   ピークメモリ、W*xと代表交換行列要素を比較して本番候補を選ぶ。
   その後で小q、Drude極限、全q、主RTへのW更新に進む。

製品コードはFortranで完結させる。新規ビルドには既存の禁止固有値ソルバー監査と
スカラーIEEE規約を適用する。既存の固定実行ファイル・本番ジョブは変更しない。
実装は `hsex_frozen_response`、`hsex_frozen_q`、`hsex_frozen_adapter`。
検証記録はcanonical calc2026に保存する。全qのW更新とスペクトル一致は本診断の対象外。
