# Localized HSE exchange and Si reference implementation plan

**Goal:** Compute an independent HSE06 Si reference using MLWF-local exchange, measuring accuracy and efficiency before interpreting spectra.

**Architecture:** Retain the Si8, 12³ primitive grid and 4³ shifted k mesh. HSE06 uses 25% screened Fock exchange with erfc(0.11 r)/r plus its matching semilocal PBE remainder. The existing occupied MLWF gauge is an acceleration only; no ELF alpha or macroscopic Axc enters HSE. Translation images and the shifted-mesh boundary twist must be retained. No k convergence study.

**Tech stack:** SALMON Fortran, existing Python/NumPy MLWF reference, Libxc7, FFT-based screened pair convolution. Numerical truth is a no-pair-truncation calculation with the same kernel and quadrature, not an assumed experimental spectrum.

## Accepted design

User approved proceeding and explicitly requested overlap-local MLWF exchange and efficiency measurements. Reuse preceding U as a localization initial guess; localize every10 RT steps, but update exchange from current occupied orbitals at every required Hamiltonian stage. Do not freeze the density matrix between localizations. Pair selection and support sizes must adapt to pump-induced broadening.

## Tasks and verification gates

1. Implement tested independent screened exchange reference in samples/hse_mlwf_reference. Tests precede code: finite q=0 kernel, analytic Fourier mode, exchange sign/spin normalization, occupied-gauge covariance, Hermitian action, finite-difference energy derivative and periodic image/twist equivalence.
2. Implement MLWF overlap-pair selection and spatial support approximation. At zero thresholds match the untruncated operator. Threshold scans report exchange-energy and action errors, retained pairs, work/memory and wall time. Compare primitive Bloch sum as an independent representation check. Use initial and propagated Si snapshots, explicitly labeling their original PZ/TDCDFT provenance.
3. Add matching semilocal HSE06 remainder using Libxc, verifying density/gradient derivatives, parameter conventions and energy normalization. Merely evaluating Fock on PZ orbitals is not an HSE ground-state calculation.
4. Integrate a self-consistent HSE Hamiltonian, including nonlocal action for arbitrary trial vectors, total exchange energy without double counting, valid SCF/restart and current/field coupling. Review before dynamics. HSE must not be enabled through removal of the existing hybrid guard alone.
5. Calculate HSE GS and impulse, then the authorized pump/probe comparison. Validate zero-field evolution, norm/energy, signed central probes and time-step behavior. If any gate is unmet, retain explicit incomplete status rather than call a frozen or postprocessed result HSE dynamics.
6. Benchmark setup/localization/pair screening/convolution/application and complete GS/RT wall times separately, fixed threads/processes, warm-up and repeated timings. Report speedups only at matched accuracy; checkpoint I/O and data conversion are separately identified. Preserve raw timings and environment metadata.

Work stays on the user's TDCDFT development branch. Review independent components before integration. Do not push.

## Status after reference validation

Tasks 1–3 completed and reviewed. Task 4 is implemented as a case-specific independent occupied-orbital HSE driver using an optional native Hamiltonian export; native general-purpose HSE remains disabled. Task 5 reached a converged all-pair occupied ground state and four short RT pilots only. Long impulse and pump–probe spectra remain open because the measured all-pair RK4 cost is ~46 seconds/step; the user has been asked to choose local optimization, HPC, or a multi-day local run. Task 6 includes repeated exchange benchmarks, complete SCF time, and short RT step timings; no parallel or system-size scaling claim. Spatial support truncation is profiling only, since its source-only energy/action pair is not suitable for variational SCF.
