# CPU局所対のOpenMP並列化

承認済み設計：MPI分割と所有対の規則を維持し、CPUバッチを使用スレッド数まで拡張する。各対の作用は独立列へ書く。MPI通信とFFTWプラン作成は並列領域外。カーネル・支持点は共有し、追加スレッドにだけFFT作業配列とプランを確保する。形状が変わるまで再利用し、破棄時に解放する。GPU/callback経路は変更しない。

1. 局所FFTにスレッド別作業領域の準備と対作用APIを追加。
2. CPU側だけ対数を広げ、エラーと処理対数をreductionで集約。
3. 端数・空・skip・周期境界とOMP1/2/4、MPI1/2/4を既存参照と比較。
4. MPIなし/OMPなしの構成を確認。実行中の5 fsバイナリは交換しない。

性能は単独実行の比較後に判断する。共有tileもバッチ幅に比例して増えるため、総メモリ増加を別途測定する。

## 検証結果

GNU MPI/ScaLAPACK版とMPIなし版のビルド成功。MPI配置111/211/221/811/222/124・OMP1/2/4のHSE/Coulomb混合周期支持試験に合格。局所CPU/バッチcallback試験MPI1/2/4・OMP1/2/4、CTest438/439とfixture計11件に合格。単一プランでworker数1→4→2→1、支持箱変更、ゼロ対、OMP無効とOMP_DYNAMICの試験も合格。性能・ピークRSSの実測は未実施。通常CTestへの追加登録はユーザー指定で確定版まで保留。
