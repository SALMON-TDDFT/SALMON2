# 局所支持ACEの対象軌道ブロック化

承認済みのメモリ削減順序の第3段階。native Gammaのpacked ACE作用を32軌道ずつ渡す。全軌道分のtarget/action作業配列を避ける。交換式・ACE構築・通信先・支持半径は維持。

全ランクが同じブロック回数を実行し、軌道分割の端数・空ブロックは0列で参加する。Taylor midpointは両端点がpackedの場合のみ適用。全交換作用、多k点、dense ACEは既存経路を維持する。32は作業単位で系サイズの上限ではない。

検証：ビルド、source ACEとpair screening回帰、128 H2 impulse16ステップを1回測定。前段階の保存結果と入力・GS・電流・エネルギーを照合する。測定差が悪ければ既定採用を再検討する。

## 実施結果

ブロック化を実装。通常版13試験・1軌道版7試験が合格。128 H2を1回測定しRSS5.1%減、時間+0.6%、電流・エネルギー一致。詳細は[実測ノート](../exx-target-blocks-ja.md)。
