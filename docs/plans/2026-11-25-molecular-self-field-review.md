# 分子近接場結合の自己場処理：物理設計レビュー

2026-11-25。対象：dff11556。実装と一次文献を照合したレビューであり、新しい補正式の実装・物理検証ではない。

## 結論

現在の本計算−自己真空参照は、環境散乱によるフィードバックを選び、分子自身の真空中の電気・磁気自己場を除く近似として実装されている。これは長さゲージに必須の操作でも、Hartree項との重複だけを取り除く処理でもない。一般的な自己放射を含む結合の標準方式として扱わない。既存の接続・保存／再開の一致は、その近似の物理的な妥当性の証明ではない。

分子全体の平均電流へ縮約する必要はない。現在の空間依存E/H入力、経路積分の逆演算による分極電流、軌道磁化電流の成分格子への返却は維持する。ただしFDTD格子で解像できる空間成分には限界があり、完全な微視的電流の離散的再現は別途検証が必要。

## 実装で確認したこと

- tools/test_grid_feedback_mpi.py の selected() は、GridFieldSeries.difference でE/Hの両方を丸ごと差し引く。
- rt/em_field.f90 の calcVbox はEの経路積分を電子のスカラーポテンシャルへ加える。磁気場は別にA_mag/cと非局所位相へ入る。
- rt/time_evolution_step.f90 は独立に分子密度のHartreeポテンシャルを計算する。LDや外部の物質の電荷は、この分子Hartree計算に含まれない。
- 電気側の返却は密度差から経路分極の時間差を求める。磁気側は実際のハミルトニアンの磁場微分と非局所位相微分から得る。単一双極子への置換ではない。
- 現在の試行・注入後の場の一致検査は、同じ分子電流を本計算と真空参照へ注入して直近の自己場が差し引かれる条件で検証された。自己放射を保持する方式へ変更しても同じ条件が成立するとは限らない。

## 場の分担として目指すもの

| 場の寄与 | TDDFTへの扱い |
|---|---|
| 入射光・外部場 | 空間依存のまま保持 |
| LD／ナノ構造による電場（縦成分を含む） | 保持。分子Hartreeには含まれない |
| 分子自身の縦のクーロン電場 | FDTDで重複して表された部分だけを除き、分子内部は既存Hartree/XCで扱う |
| 分子自身の横電場・磁場 | 半古典的な自己放射を扱う方針では保持 |
| 環境で散乱して分子へ戻る電場・磁場 | 保持 |

ここで縦成分とはcurlがゼロの電場、横成分とはdivergenceがゼロの電場を指す。空間平均や遠方場への置換ではない。近接場は両方を含み得る。全電場の縦成分を一律に捨てると、ナノ構造由来の重要な近接場まで失う。

## 推奨する検討案（まだ未実装）

物理的な目標は次の分担である。

    E_drive = E_total - E_molecule,self,longitudinal,vacuum
    B_drive = B_total  （分子の位置は真空なのでH=B）

E_total/B_totalは、入射場、LD、分子電流をすべて含む本計算の場。差し引くのは分子が作る縦のクーロン電場だけであり、時間発展する自己真空FDTDの全場ではない。補正後のE/Bを既存の多極子型長さゲージの経路積分へ渡す案とする。

離散化を含む検討手順：

1. まず実装のFD電荷と電流の対応を定義する。現在の経路分極をP_fとすると、候補は delta_rho_f=-D_f(P_f(t)-P_f(0))。J_P=(P_f[n]-P_f[n-1])/dt、J_M=c C_f M に対し、D_f C_f=0と電荷連続則を検証する。これだけで細かい電子格子の密度を厳密再現すると主張せず、電荷・双極子・高次モーメントと格子依存も調べる。
2. 同じFD電荷・勾配／発散・境界条件に整合する真空Poisson演算から分子の縦電場を得る。電子格子で計算したHartreeの勾配を単に補間して引くと、異なる格子の静電Green関数の差が残る。どの補間・射影が同じ結合エネルギーを与えるかも導く。
3. FDTDが初期静電場なし・電流源から開始する現在の設定では、補正の基準もrho(t)-rho(0)に合わせる。固定イオンの差分はゼロ。初期静電場を含むモデルや複数分子への拡張では別途分担を定義する。
4. ナノ構造の誘起電荷を補正Poissonの源に入れない。複数の独立TDDFT領域では他領域のクーロン場まで除かない。PML、開放境界、周期像の扱いも同一視しない。
5. 自己放射を保持すると、注入した電流が同じステップの分子駆動へ直接戻る。既存のゼロ電流予測をそのまま受け入れず、時間ステップの配置と反復／予測修正を再導出する。既存の直接保存点は各試行を同じ開始状態へ戻すために再利用できる。
6. 同じ作用・離散化から物質と場のエネルギーの帳簿を定義する。HartreeとFD縦電場エネルギーを二重計上しない。場だけを変更して既存の収支診断をそのまま正しいと扱わない。

## 最初に行う検証

- 合成の移動電荷／局在電流で、FD電荷連続則・Gauss則・仕事量と、境界を含む勾配／発散の整合を確認する。
- 真空中の調和振動子などで、縦自己場の二重計上がなく、半古典的放射によるエネルギー移行が帳簿と一致するかを確認する。自然放出の完全な量子論とは区別する。
- ナノ構造が与える既知の静電的な非一様場が、補正によって消えないことを確認する。
- その後C2H2で一方向入力との比較・双方向の収支・格子／dt依存・保存／再開を検証する。新しい実計算は今回行っていない。

## 一次文献と適用上の区別

- Bonafe et al., Full minimal coupling Maxwell-TDDFT, https://arxiv.org/html/2409.08959v2 , Sec.II Eq.(1),(7),(10),(11)：Hartreeを保持し、横場を結合する構成と電荷連続則。全物質のクーロン相互作用を量子側で扱う条件を、本件の分子＋古典LDへそのまま拡張できない。
