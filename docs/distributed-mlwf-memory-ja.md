# Γ点MLWF行列の分散化（2026-09-29）

> 2026-10-06：本記録中の`developer_tests`は当時のローカル開発検証です。GitHub配布から除外しました。通常の回帰試験は`testsuites`を使用します。

[ACE計量行列の分散化](distributed-ace-memory-ja.md)に続き、native Γ点のMLWFゲージ、6本のリンク行列、輸送用SVDと初期シードの行列を空間×軌道MPIランクに分散した。

## 採用状態

実計算比較とユーザーの選択により、通常計算はACEのみ分散し、MLWFは従来経路を使用する。本モジュールは比較検証用に保持する。以下は任意の`comm_matrix`を渡した場合の実装仕様であり、通常経路の自動選択ではない。

## 対象と使い方

HSE06/PBE0/PBEhのnative Γ点実空間経路で、ScaLAPACKが有効かつ空間×軌道ランク数が2以上かつ呼出し側から`comm_matrix`を渡す場合に使用する。新しいnamelist変数はない。1ランク／ScaLAPACKなしでは従来経路を維持する。多k点Wannier経路とDC-LCFO内部の局所化処理は今回の対象外。

バッファ付きDC-SCFで局所化を無効にした設定は、そのまま正準軌道を使う。DC-LCFO→RTでは実空間に再構成した波動関数に本経路を適用する。交換率、占有数の重み、局所化半径、支持領域、収束閾値は変更しない。

## 実装

- `s_exx_gauge`に2次元ブロック巡回分散のゲージと行・列対応を保持する。全N×N行列の集約は行わない。
- 重なり・リンク行列はメッシュ列を逐次通信して担当部分だけ構築する。
- 前ステップの局在軌道との重なりからScaLAPACK SVDでUを輸送する。再シードも分散固有値計算で行う。
- Γ点Jacobiの対順序・角度・収束判定を維持する。まず各対の2×2ブロックで必要性を判定し、回転が必要な対だけ2列・2行を通信する。角度はrank 0で決定して配信する。
- 波動関数の局所化と交換作用の逆変換（U†）も列単位で行う。分散行列を一時的に全ランクへ複製する処理はない。
- BLACSコンテキストは各更新中だけ保持する。状態コピーは配列を独立に所有する。MPIコミュニケータは借用するため、状態より長く存続させる。
- 局所化が収束しない場合の受理済みゲージ保持、特異輸送時の単位行列へのリセット・再シードも維持する。

ほぼ縮退した特異値がランク間で約10⁻¹⁵異なる試験で、`PZGESVD`が`INFO=N+1`を返した。これは[ScaLAPACK仕様](https://www.netlib.org/scalapack/explore-html/dd/d2b/pzgesvd_8f_source.html)のランク間不一致の通知である。この場合は得られた特異ベクトルを組み合わせず、元の重なり行列から分散Newton–Schulz法で同じ極分解のユニタリ因子を求め直す。最小特異値1e-8の判定は全ランクで維持し、`||U†U-I||F <= 1e-12 sqrt(N)`を満たした場合だけ使う。100反復で満たさなければ従来のリセットへ戻る。未収束など他のSVDエラーを無視する処理はない。

## メモリと通信

大行列のアプリケーション側配列は各ランクO(N²)からO(N²/P)へ削減される。通信用行・列、対角要素、特異値などにO(N)が残る。ScaLAPACK内部作業領域とメッシュ波動関数は別に必要。

保持ゲージの実際の確保量（最大ランク）：

| 軌道N | MPI P | 従来/ランク | 分散後/ランク |
|---:|---:|---:|---:|
| 32 | 2 | 16 KiB | 8 KiB |
| 32 | 4 | 16 KiB | 4 KiB |
| 2 | 8 | 64 B | 16 B |

最後の例は空タイル用のパディングを含む。これは保持ゲージ単体の値で、RSSや全体ピークメモリではない。6本のリンク行列も同じ局所行列形状で確保する。

1 sweepの通信量はO(N² + N×実際に回転する対数)、集団通信回数はO(N²)。従ってメモリ削減を計算速度の改善と同一視できない。64・128 H₂での実時間・ピークRSSを[実計算比較](matrix-memory-tradeoff-ja.md)に記録した。より大きい系・多ノード性能は未計測。

## 検証

GNU Fortran / Open MPI / ScaLAPACK / OpenBLASで確認：

- MPI/ScaLAPACK有効ビルドと、MPI・ScaLAPACKなしのHSE有効ビルドが成功。
- 32軌道のMPI 1/2/4（空間・軌道・混合分割）、2軌道のMPI 8（空軌道ランク・空タイルを含む）の8配置に合格。ScaLAPACK無効の同じ8配置も合格。
- 初期局所化は32軌道の全配置で従来同様6 sweep。spread差1e-8、局在軌道差1e-7以内。
- U†による復元、複素位相変化後の輸送、特異輸送からの再シード、未収束時の受理済みゲージ保持、コピー元解放後の作用、不正な前ステップ状態の集団的拒否を確認。
- HSE06/PBE0/PBEh(40)の短いimpulse RT、入力ガード、交換対省略後の逆変換を含む10試験に合格。並列配置の電流・エネルギー比較は既存の許容値2e-8以内。
- 読み取りによる独立レビューを実施。Fugaku/NVHPC/GPU環境では今回の変更を未検証。

```sh
python3 developer_tests/651_hybrid_exchange/gauge/run.py --build /path/to/mpi-build
python3 developer_tests/651_hybrid_exchange/gauge/run.py --build /path/to/mpi-build --no-scalapack
```

試験は現行ソースを一時領域に境界検査付きでコンパイルする。`MPIFC`、`MPIEXEC`、`BLAS_LIBS`、`FFTW_LIBS`、`SCALAPACK_LIBS`で環境を指定できる。

## 残る削減対象

`orbital_hermitian_action`の密行列、LCFO関連の一時配列・同時保持、実空間波動関数とそのコピーが残る。全メッシュ波動関数は全体でO(Ngrid N)の記憶量を必要とし、今回だけで全計算のメモリが線形化したとは言えない。
