# 局所支持ACEの対象軌道ブロック化

2026-09-29。前段階の[作業領域寿命整理](exx-workspace-memory-ja.md)に続く変更。

## 対象

native Γ点のpacked（局所支持）ACE作用で、対象波動関数と交換作用を最大32軌道ずつ確保し、実空間波動関数へ加算する。32は内部の作業単位で、計算可能な軌道数の制限ではない。入力変更は不要。

通常のdense ACE、多k点、全交換作用の経路は維持する。Taylor midpointは両端点ともpacked ACEの場合にブロック化する。支持領域・ACE構築・交換率は変えない。

軌道方向の担当数の最大値から全ランク共通の反復回数を決める。各ランクの最終ブロックは担当数に合わせ、空ブロックも0列で既存のACE通信に参加する。作用の加算先は各ブロックの軌道番号へずらす。

ACE更新時に全軌道分の配列が必要になった場合、形状が合わないブロック配列は先に解放する。全軌道分とブロック分を不要に同時保持しない。

## メモリと速度

128 H₂・MPI 8の対象＋作用作業領域は、全128軌道では256 MiB/ランク、32軌道なら64 MiB/ランク。ただしACE更新・MLWF更新は全軌道処理を維持するので、プロセス全体のピークRSSが192 MiB減る保証はない。

既存のpacked ACE内部は既に対象を1列ずつ処理するため、同じ対象数に対する主な演算・通信は維持される。ブロックごとの検査と通信準備は増える。小さすぎるブロックの速度低下を避けるため32軌道としているが、最適値の探索は未実施。

## 検証

GNU MPI/ScaLAPACKビルド成功。通常版でsource ACE 7試験、pair screening 6試験が合格。HSE06/PBE0/PBEh(40)、空間・軌道分割、SCF/RTを含む。さらに計測用コピーだけを1軌道ブロックに変更し、同じsource ACE 7試験を通してブロック境界の加算を確認した。1軌道版は通常バイナリに採用していない。富岳・GPUは未検証。

## 実測

128 H₂、MPI 8・OMP 1・BLAS 1、保存済みDC GS→impulse 16ステップ、各1回。入力ハッシュとGSパスを照合した。

| 指標 | 寿命整理後 | ブロック化後 |
|---|---:|---:|
| 最大RSS (MiB/ランク) | 3073.5 | 2917.1 |
| 秒/step | 11.979 | 12.050 |
| RT 16ステップ (秒) | 191.66 | 192.80 |

RSSは156.5 MiB/ランク（5.1%）減少。時間差は+0.6%で、各1回のため有意な速度差とは判断しない。メモリはSALMONプロセスの初期化を含む生存期間全体の最大RSS。

電流最大差1.016e-20、全エネルギー最大差9.948e-13 Haで、比較基準2e-8以内。[集計JSON](reports/exx-target-blocks/summary.json)。局所支持の条件・交換対選別は変更していない。

ACE分散採用直後の3451.7 MiB/ランクに対し、寿命整理と本変更を合わせて約15.5%減少した。全体の記憶量の次数を変える変更ではない。次の大きな削減対象は局在軌道の全メッシュ保存と、ACE構築・MLWF更新中の全軌道配列である。
