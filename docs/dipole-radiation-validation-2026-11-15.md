# One-way dipole → native FDTD validation

## Scope

Public DipoleMap distributes laboratory-frame physical charge dipoles over explicit
FDTD macro cells, retaining molecule and field-point IDs. Polarization and current
are in atomic units. drive_native_dipoles validates/agrees a whole trajectory
before stepping a borrowed fresh NativeEHField. Native interpolation/deposition
and numerical updates were not changed for this feature.

This is electric-dipole, one-way coupling: no self-field feedback, initial static
dipole electrostatics, radiation reaction, resolved molecular current density or
converged emission spectrum is claimed. All trajectories explicitly hold p0 for
one step to satisfy native zero-initial-current initialization. Returned j times
are interval midpoints; E times are native integer steps, including zero.

## Evidence

- Pure tests: unequal-volume integrated polarization/current equal summed molecular
  dipole/dipole derivative; superposition; static offsets; immutable ownership;
  malformed maps, complex/nonfinite values and invalid dt rejected.
- Native synthetic impulse, 40³ vacuum grid, spacing 2 bohr, dt=.003 au, 64 steps:
  first nonzero sampled E matches -4*pi*dt*S*S^T*j to rtol2e-13, atol1e-18.
  Remote E max 9.956361320964561e-8 au, with zero incident-wave amplitude.
- One and two field ranks (two/three total ranks): saved E/j/time arrays exactly
  equal. Nonzero first interval and rank-local trajectory mismatch both rejected
  before advancing the field.
- Recorded C2H2 total charge dipoles from the isolated E-worker test: 21 field
  steps after explicit initial hold, dt=.04134137333656136 au, spacing20 bohr.
  Remote E max 6.270486770954488e-10 au. No field fed back into TDDFT.
- Existing explicit embedded library SHA256:
  1e9abfa895dc216399377c164c0cbefa606c436c7e7eee920f4aa8901fbdae2a.
  It is verified against its build record at load. No new native build for this
  feature; no assertion that this older binary supports the new E1 worker.

MPI runs used one thread per process, maximum three ranks, bounded at 45 seconds
per case on local Apple Silicon. No GitHub Actions or network downloads. RSS was
not measured or hard-limited. Source suite: 402 tests passed, one platform skip.

## Reproduction

With explicit matching embedded build record and MPI-enabled Python environment:

```sh
mpiexec -n 2 python tools/test_dipole_radiation_mpi.py BUILD_JSON NEW_OUTPUT_2
mpiexec -n 3 python tools/test_dipole_radiation_mpi.py BUILD_JSON NEW_OUTPUT_3
mpiexec -n 2 python tools/test_dipole_radiation_mpi.py BUILD_JSON NEW_MOLECULAR_OUTPUT DIPOLES_NPZ
```

DIPOLES_NPZ is generated by tools/test_isolated_worker.py, with values[:,3:6]
containing total charge dipoles in e*bohr including t0. Do not use E-worker's first
three values as periodic matter current. Set OMP_NUM_THREADS and BLAS thread
counts to 1, and use the bounded launcher pattern in run_parallel_mpi_tests.py.
No implicit compile, runtime acquisition or molecular interpolation is performed.

## Distribution and review

sdist-to-wheel build passed. Fresh wheel installed in a separate virtualenv:
402 tests completed with no failures (two skips: platform/optional dependency),
and the NumPy-only example passed. Using that installed interpreter with `-I`,
the two-rank recorded-C2H2 native FDTD case also passed; E/j/time arrays exactly
matched the source-package run. Source suite's single skip is platform-related.
AI JSON guide synchronization and whitespace checks passed.

Read-only review found no required numerical/timing/conservation change. Calling
with a valid NativeEHField on every field rank is a collective precondition;
passing a wrong object on one member is outside that contract. No whole-trajectory
rollback or generic communicator inference is provided.
