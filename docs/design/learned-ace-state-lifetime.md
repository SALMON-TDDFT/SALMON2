# 学習ACEの共有状態と寿命

`exx_native`のSAVE状態は、SALMONの既存EXXアダプタがGS/RT呼出し間で保持する計算フレームワーク状態である。Coding Rulesの deliberately shared framework state の例外として扱う。任意の新規汎用ルーチンのグローバル変数を許可する趣旨ではない。

- `factor_history(:)`：k点ごとのrank-local ACE因子履歴。異なる時刻の呼出し間で予測に必要。分散格子/k点の所有範囲は当該MPI rankに従う。
- `factor_step`、初期化・設定・予測状態フラグ：時間ステップ境界と現在のACEキャッシュを対応付ける。begin/endpointが所有し、Hamiltonian作用呼出しは同じ状態を参照する。
- 確定したRTステップのendpointで履歴を採用する。予測子・中間評価の時間が前後しても、それ自体を履歴へ登録しない。
- 共有はMPIプロセス内部に限る。複数の独立したRT系を一プロセス内で同時に進めるAPIではない。状態を更新する手続きはOpenMPの並列作用ループから同時呼出ししない。
- プロセス内で別系へ再初期化して継続することや、学習モデルのcheckpoint/restart互換性をこの保存宣言だけで保証しない。

履歴データ自体の更新・予測アルゴリズムは`s_factor_history`を明示引数として受け取る。アダプタのSAVE状態は既存公開APIの呼出し間連携のために残した。将来、一プロセス複数系対応を行う際は他のEXXキャッシュも含め計算コンテキストへ移す。今回の対応は寿命と所有者の明確化であり、数値アルゴリズムや保持フレーム数は変えていない。
