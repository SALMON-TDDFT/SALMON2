# 固定 LCFO 部分空間での RT 経路を削除

DC-SCF、DC-LCFOのGS対角化、保存データから初期実空間波動関数を再構成する処理は維持した。RTでは再構成した実空間波動関数を直接時間発展させる。固定LCFO基底へのHamiltonian射影、係数空間Taylor伝播、LCFO専用交換・ACE経路を削除した。再構成では必要な係数をストリーム読取し、RT用の基底を保持しない。

専用のyn_hse_lcfo_*とhse_lcfo_*入力は削除した。古い入力はこれらの項目を除去する必要がある。yn_dc_lcfo、LCFO固有値ソルバー、DC断片・バッファ指定は維持する。現行の実空間交換でも使うlcfo_wf_supportは削除対象から除外した。

この変更は実空間ACEの軌道空間行列を分散する実装ではない。残る複製行列のメモリ評価は、実空間RT経路を対象に行う。旧LCFO係数経路でのメモリ見積りをそのまま実空間RTに適用しない。

実行中の比較計算と固定バイナリ、既存の出力は変更しない。

非HSEビルド検証で、既存チェックポイント処理のexx_native参照がUSE_HSEで保護されていない問題を確認した。専用importと呼び出しに条件ガードを追加し、共通のエネルギー参照・波動関数I/Oは変更しない。
