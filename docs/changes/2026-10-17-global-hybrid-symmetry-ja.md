# PBE0/PBEhの対称性FFT再利用

`yn_exx_fft_orbits='y'`をHSE06だけでなく、PBE0、PBEh40、PBEh40+rVV10にも
許可する。固定イオン、整数占有、全軌道保持、CPU・k点並列、全q点、
立方実空間・kメッシュ、直交セルを前提とする。
対称性なしの大域ハイブリッド経路、SR局所化、学習ACEの範囲は変更しない。

大域ハイブリッドを一律にWannier経路へ送る入力処理を、上記の対称性経路に
限って除外した。再利用なしの参照計算も同じ代表軌道を使用する。
PBE0等では既存の非遮蔽・球形切断クーロンカーネルとq=0処方を使用する。
カーネル式、切断半径、交換混合率、rVV10項は変更しない。
保持群の閉性とRT電場方向の保存を全ハイブリッドで検査し、
今回の大域ハイブリッド対称性経路では可動イオン・BOMDを拒否する。

## 検証

記録先は `work/global-hybrid-orbits-20261017`。

- 変更前はPBE0の再利用入力がHSE専用ガードで拒否されることを確認。
- 非遮蔽交換作用の通常・シフト付きメッシュ、既定・明示切断半径、
  strided/contiguous FFT、並進操作、1/2/4 MPIの12条件を比較。
  最大相対差5.95e-16。
- PBE0/PBEh40/PBEh40+rVV10のSi初期2 SCFの固有値差は最大4.71e-15 au。
- PBE0 Siは残差3.00e-9、PBEh40対称H4セルは2.72e-9まで収束。
  H4収束GSの再利用有無の固有値差は6.67e-16 au。
- 同一収束GSからPBE0・PBEh40それぞれ8step RTの有無比較を実施。
  電流を含むrt出力差は1.36e-19以下、energy出力差は2.14e-14以下。
- PBE0で電場を反転する群を変更前に受理する問題を再現し、修正後の拒否を確認。
  未対応MDの入力拒否と有効なRT群の正常終了も確認。
- 440番に小さなPBEh40対称性GS回帰を追加。収束、FFT対象点削減、
  再利用なしの参照エネルギー、Wannier経路を使わないことを検査。
- 独立レビューで見つかった電場検査・MD制限の欠落は修正し、再レビュー済み。
- MPI/HSE/LibXC/ScaLAPACK、serial HSE、serial non-HSEの3ビルドが成功。
  既存422/423/424の9工程と新規440の3工程が合格。
  新規テストの最初の実行ではsym.datが準備されず失敗したため、
  preparationでの生成を追加して3工程の合格を確認した。

粗いSiセルのPBEh40は最初の2種類のSCF条件で未収束だったため、結果を保持し、
収束GS・RTの検証には対称H4を使用した。初期2 SCF一致はSCF収束の主張ではない。
PBEh40+rVV10は今回GS初期反復の比較のみ。長時間物理計算と性能測定は実施していない。
Fujitsu・GPU・EigenExaは未検証。restart試験をtestsuiteへ追加していない。
