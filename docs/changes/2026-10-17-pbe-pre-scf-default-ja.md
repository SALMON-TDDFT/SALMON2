# 対応する新規ハイブリッドGSでPBE先行を既定に

`exx_pre_scf_threshold`を省略した場合、対応する新規・静的ハイブリッドGSで
`1d-4`へ解決する。明示的な`0`は無効化、明示的な正値は指定値を保持する。
3回連続の密度残差判定、混合履歴の初期化、目的ハイブリッドへの切替と
最終収束条件は既存実装のまま。

自動有効化はRT/restart、非ハイブリッド、MD/最適化、未対応の密度混合・
収束指標、checkpoint/shutdown、診断snapshot、正温度未指定のDCでは行わない。
明示的な正値については従来の非対応入力エラーを保持し、可動イオンも拒否する。
省略判定は全入力のMPI配布後、ログ・入力検査前に全ランクで行う。
`variables.log`には解決後の値を出力する。

## 検証

`work/pbe-pre-scf-default-20261017`に入力・ログ・SHAと検証記録を保存。

- 変更前に省略入力のPBE段階が存在しないことを再現。
- 対称H4/PBEh40で既定PBE段階、3連続判定、15反復目での切替、
  目的ハイブリッドの最終収束（残差8.55e-9）を確認。
- 明示的0/正値、非hybrid、RT、restart、MD、potential指標/混合、
  checkpoint、shutdown、診断、DC温度、非対応明示指定の14入力を確認。
  不適合な全体入力については解決値と適切な拒否を確認し、正常計算とは区別。
- 有効なLibxc PBEとPBE0 RTは自動閾値0で正常終了。
- MPI/HSE/LibXC/ScaLAPACK、serial HSE、serial non-HSEの3ビルドが成功。
- 422/423/424/440の準備・実行・検証、計12件が合格。
  422でDCのPBE先行と全fragment同期切替を、440で既定PBE先行を確認。
- 読取りのみの独立レビューで具体的不具合なし。

固定反復数の短い交換演算比較では明示的0を指定する必要がある。
PBE段階を含めてnscfを消費し、PBE/最終ハイブリッド未収束ならGS出力を拒否する。
速度向上率は今回測定していない。Fujitsu・GPU・EigenExaは未検証。
restart試験をtestsuiteへ追加していない。先行する未commit対称性拡張は保持。
