# HSE／PBEh(40)+rVV10 分散化・ビルドノート

更新日：2026-09-28  
対象ブランチ：`pbeh40-rvv10-water-md`

## ビルド

SALMONの通常の入口は `configure.py` です。ScaLAPACKを有効にするオプションは
**`--enable-scalapack`（ハイフン2つ）**です。内部でCMakeの
`USE_SCALAPACK=ON`に変換されます。

富岳向けには、リポジトリ直下から新しいビルドディレクトリを作成します。

```sh
mkdir build
cd build
python3 ../configure.py --arch=fujitsu-a64fx-ea --enable-scalapack
make -j 8
```

実行ファイルは `build/salmon` です。このアーキテクチャ指定ではMPIとネイティブHSEも
有効になります。一般のMPI環境では、その環境に合うコンパイラ・ライブラリ設定と
`--enable-mpi --enable-scalapack`を使用します。

ビルド時のScaLAPACK有効化と、入力ファイルでのLCFOソルバー選択は別です。
新しい全対角化経路を使う場合は、入力の `&dc` に以下を指定します。

```fortran
&dc
 yn_dc_lcfo='y'
 yn_dc_lcfo_diag='y'
 lcfo_eigensolver='scalapack'
/
```

これは既存入力へ追加する指定例です。フラグメント数・状態数・並列数などは対象系に
合わせて設定します。ScaLAPACKなしのビルドでは、この選択は明示的に拒否されます。
既存の `lapack` と `chefsi` は残しています。新しい `scalapack` 選択は複素LCFO用です。

ビルドの詳細は [HSEビルド](hse-build.md) と
[プラットフォーム別説明](hse-platforms.md) を参照してください。

## 今回の分散化

| 部分 | 実装した内容 | 残る共有・制約 |
| --- | --- | --- |
| ネイティブ交換 | HSE／PBEhのMLWF更新、交換作用、ACE構築・作用を空間と軌道の両方向に分散 | 軌道間のゲージ・重なり・ACE計量行列は共有 |
| LCFO行列構築 | Hψと射影をローカル空間領域で計算。コア基底の収集とハロー転送を領域単位に変更 | フラグメント代表ランクの出力用基底・受信ハローなどは残る |
| 複素LCFO全体対角化 | Hamiltonianと固有ベクトルを2次元ブロックサイクリック配置で保持し、PZHEEVで対角化 | 固有値、フラグメント行列・係数バッファは必要な範囲で共有 |

新しいLCFO全対角化経路は、フラグメントの対角・ハローブロックから直接分散行列を
組み立てます。全体行列を代表ランクへ集めず、出力時にも各フラグメントに必要な
固有ベクトルの行だけ回収します。従来のLAPACK経路の全体行列複製は変更していません。

全対角化であるため、全体としての行列記憶量は二次、演算量は三次の増大が残ります。
固定のメモリ上限は追加していません。特定の配列の分散と、プロセス全体のピークメモリは
区別する必要があります。

## ネイティブSCF・実時間発展の対応範囲

- HSE06／PBEh(40)／PBEh(40)+rVV10の通常SCFとDCフラグメントSCF。
- DC-LCFOから実空間メッシュへ波動関数を再構成した後の、HSE固定イオンの応答・パルス計算。
- 同じ再構成経路からのPBEh Ehrenfest計算。レーザー励起中の電子占有数は固定し、電子温度への当てはめは行いません。

実時間発展は実空間メッシュ上で行い、LCFO基底への射影を保持する経路ではありません。
HSEのイオン運動は未対応です。

新しいネイティブ交換の分散経路は、無シフトΓ点、直交セル、
`exx_mlwf_radius=0`（全領域積分）、x方向を分割しないy/z空間分割を対象とします。
`nproc_ob`で軌道分割を併用でき、不均等分割にも対応します。ただしSALMON本体の
時間発展の制約により、各軌道グループには最低1状態が必要です。

通常SCFは占有状態のみ・固定占有数、DC SCFは部分占有にも対応します。
有限半径、多数k点、既存の射影RT、通常BOMDはそれぞれ従来の対応範囲を維持します。
新経路の再開・チェックポイント・スナップショットには未対応の制約があります。
詳細は [入力と対応範囲](inputs/hse.md) を参照してください。

MLWFの制御名は `exx_mlwf_interval`、`exx_mlwf_maxiter`、
`exx_mlwf_tolerance`です。旧 `hse_mlwf_*` 名は互換入力として残しています。

## 入力例と診断

- [通常SCF：空間2×軌道2、計4 MPIランク](../samples/hse_spatial/h4_orbital_scf.inp)
- [DC SCF：2フラグメント×空間2×軌道4、計16 MPIランク](../samples/hse_spatial/h4_orbital_dc_scf.inp)
- [ScaLAPACK全体対角化：計4 MPIランク](../samples/hse_spatial/h4_scalapack_dc_scf.inp)

各例では `H_rps.dat` を実行ディレクトリに配置します。DCの
`nproc_rgrid_tot`も実際に起動する全ランク数に整合させます。

出力の `EXX_ORBITALS` は局所／全体軌道数と局所格子点数、
`LCFO_DENSE` は局所行列の行数・列数と全体次元を示します。
`LCFO_SCALAPACK` が新しい全対角化経路の診断印です。

## 検証と未検証事項

実行検証環境はApple Silicon、GNU Fortran、MPI、OpenBLAS、FFTW、ScaLAPACKです。
富岳向け設定の説明はありますが、今回の富士通コンパイラでの実ビルド・実機実行は未検証です。

- 交換・MLWF・ACE：108比較ケース。交換作用の最大差は約 `5.52e-15`。
- ネイティブSCF・DC・実時間発展・Ehrenfest：30テスト通過。水の4軌道を3グループに分けた不均等分割も検証。
- 分散全対角化：24行列ケース。1〜6ランク、ランク順序の反転、空の局所行列、部分係数の回収、非エルミート入力の拒否を検証。
- HSE／PBEhのDCと再構成後の応答：2／8ランクでLAPACKと比較。固有値差は最大約 `1.95e-11 Ha`。
- 複素Si：4 k点・192固有値の既存検証が通過。
- ScaLAPACK有効／無効、HSE無効のビルドを確認。ScaLAPACKなしの既存SCF/DC/RT回帰13件も通過。

これらは数値整合性の検証です。巨大な水・溶液系での実行時間、ピークメモリ、
長時間のEhrenfest軌道、および富岳でのスケーリングは今後の評価対象です。

主要実装コミット：`b6655232`（ネイティブMLWF/ACE軌道分散）、
`1c4e6795`（複素LCFOのScaLAPACK全体対角化）。
