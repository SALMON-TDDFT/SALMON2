# 局所支持 ACE 検証

64 H₂、8×1×1 フラグメント、MPI8、同じ DC-LCFO seed、99.9%支持。
`occupied` と `source` の違いは ACE の構築用軌道のみ。
`pilot-2steps.json` は2ステップの予備試験で、スケーリング測定ではない。
入力・出力・電流・エネルギー・各ランクRSSを tar に保存。

|方式|RT 2ステップ 秒|最大ランクRSS MiB|生成候補／更新|FFT対／更新|
|---|---:|---:|---:|---:|
|occupied|10.691|1146.875|4096|4096|
|source|6.0587|1106.328|1184|320|

Source ACEは5/5更新で受理、フォールバック0。電流差最大1.293e-11、
全エネルギー差最大1.4574e-4 Ha。これは支持空間変更による近似差で、
ゼロ重なり対の除外誤差ではない。16ステップでの確認は別記する。
比較に用いた実行ファイルの SHA256 は JSON に記録。

独立負定値対角作用素による非直交ACE補間と、複素・重なりあり有限支持の
交換作用／厳密なゼロ対除外／ACE補間を、MPI1–8、軌道分割1–8、
omega=0/.11/.3 の27構成で検証した。
全支持のnative RTは従来方式と一致し、99.9%支持のMPI空間・軌道分割でも一致した。
従来の入力・adaptive RT・PBE pre-SCF・半径優先・対省略を含む41テストが成功。

## 16ステップ比較（各1回）

同じ64 H₂・MPI8・99.9%支持で、occupied 92.625秒、source 54.860秒
（1.688倍）。最大ランクRSSは1146.078 / 1140.875 MiB。
Source ACEは33/33更新で受理、フォールバック0。
電流差最大1.201e-10、全エネルギー差最大1.4574e-4 Ha。
impulse後のエネルギー変動幅はoccupied 5.826e-6 Ha、source 7.211e-6 Ha。
短時間の一致検証であり、長時間安定性や水系の物理収束を保証しない。
`comparison-16steps.json`と同名tarに結果と生データを保存した。

独立レビュー後、フォールバック前の失敗した試行のFFT処理数も合算するよう修正した。
上記試験はフォールバックが0回なので影響しない。新旧実行ファイルの時間は
スケーリングの同一系列に混ぜず、正式な再計測は修正後の実行ファイルで行う。

修正後はHSE native RTと強制フォールバック検証を追加した44テストが成功。
強制拒否は一時コピーをコンパイルした試験用実行ファイルだけに注入し、
本番の入力や実行経路にテスト用スイッチは設けていない。
MPI1、空間MPI2、軌道MPI2で再計算を含むFFT処理数と従来結果の一致を確認した。
`validation-logs.tar.gz` に失敗再現と成功のログを保存。
