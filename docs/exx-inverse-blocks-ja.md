# 交換作用の構築・逆変換のブロック化

2026-09-29。[前回の変更](exx-target-blocks-ja.md)はpacked ACE作用の対象配列をブロック化した。今回は対省略経路で、局在軌道に対する交換作用と、その正準軌道への逆変換をブロック化する。

## 実装範囲

`apply_exchange_action`の対省略／診断経路では、従来は全軌道分の`localized_action`とN×Nの`adjoint`を作っていた。これを32軌道ずつ計算し、`K(WF) U†`をBLASの行列積で出力`w`へ加算する。`adjoint`は必要な行だけ作る。

空間並列だけならブロック作用を直接行列積に使い、通信のためのコピーは作らない。軌道並列では各所有ランクのブロックを配信し、そのブロックに対応するU†を使う。担当軌道が尽きたランクも空ブロックで作用計算の通信に参加する。

最終出力`w`はACE構築に必要なので全軌道分を保持する。全メッシュ×全軌道の配列をすべて除去したわけではなく、今回なくすのは逆変換前の中間配列。source-support ACEの構築経路、対省略無効の直接作用、検証用の分散MLWFゲージ経路は今回の対象外。

## 対省略と統計

`spatial_exx_apply`へ任意引数`screen_target_count`を追加し、各ブロックでも全ターゲット数を分母とする対省略の予算を維持する。指定しない既存呼出しは従来動作。ブロックごとに許容誤差が増えることはない。

誤差境界はブロックの二乗和平方根、候補・省略・積・カタログ・評価点数は和で集計する。拒否されたACE試行を含むFFT仕事量もブロックごとに積算する。

## 検証

GNU MPI/ScaLAPACKビルド成功。通常32軌道版の対省略SCF/RT 6試験と、1軌道ずつ処理する境界確認版の同じ6試験が合格。PBEhの空間分割対軌道分割の一致も含む。既存source ACEの7試験にも合格。富岳・NVHPC/GPUは未検証。

## 実測と採用判断

| 指標 | 従来の全軌道逆変換 | 32軌道ブロック |
|---|---:|---:|
| 最大RSS (MiB/ランク) | 974.9 | 980.6 |
| 秒/step | 5.934 | 6.195 |
| RT 16ステップ (秒) | 94.95 | 99.13 |

各1回で、時間は約4.4%増、RSSは約0.6%増。今回の64 H₂では全体ピークの改善を確認できなかった。ピークは初期化も含むプロセス全体のRSSで、中間配列単体の確保量とは異なる。小さな差の有意性は未評価で、大規模系での効果を否定する結果ではない。

電流最大差1.016e-20、全エネルギー最大差9.948e-14 Haで、比較基準2e-8以内。[集計JSON](reports/exx-inverse-blocks/summary.json)。

この結果を受け、通常経路への採用は保留した。`use_blocked_inverse=.false.`が既定で、以下の比較用ビルドだけで有効にする。前回までに採用したACE分散、寿命整理、packed ACE作用側のブロック化は維持する。今回の実装は全軌道の最終作用をなくすものではなく、ピークの支配項を追加で調べる必要がある。


## 再現

`testsuites/benchmark_matrix_memory/run.py`を`--states 64 --repeats 1 --modes ace`で実行した。基準入力は保存済みの64 H₂ DC GS→実空間RTから、`exx_ace_support='occupied'`、`exx_pair_screening='diagnose'`、`exx_pair_tolerance=0d0`へ変更。0.999支持、MPI 8・OMP 1・BLAS 1、impulse 16ステップは両方で同じ。

変更前バイナリは同じコンパイル済みオブジェクトを使用し、`exx_native`の`apply_localized_blocks`への分岐だけを外して従来の全軌道作用・逆変換を呼ぶ比較用コピー。測定後、通常ソースの実験用スイッチは無効へ戻した。実行ファイル、比較用ソース、コンパイル／リンクコマンド、入力・出力はローカル`work/exx-inverse/`に保存。

この診断条件は逆変換のメモリ・速度を切り分けるために選んだもので、以前のsource ACE条件の時間とは直接比較しない。無外場計算・電流差引きは行わない。

比較用バイナリは次で再作成できる（新しい出力ディレクトリを使う）：

```sh
python3 testsuites/benchmark_matrix_memory/build_inverse_variants.py \
  --build /path/to/mpi-scalapack-build --output /path/to/inverse-variants
```

`before`は既定、`after`は32軌道ブロック、`boundary`は境界検証用1軌道ブロック。通常ソース・ビルドオブジェクトは書き換えない。各ディレクトリのmanifestを既存の測定runnerに渡せる。
