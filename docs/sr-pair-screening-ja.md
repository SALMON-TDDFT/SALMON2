# HSE：WFの裾と離散SRカーネルによる軌道対省略

球状WF支持と既存FFTを維持したまま、交換寄与の診断と任意有効化の軌道対省略を追加しました。
既定値は無効です。診断は全対を計算し、省略を有効にすると、誤差予算とACE検査を満たす場合だけ省略結果を採用します。
高速化を保証するものではなく、閾値ごとの候補数と判定・補正コストを測るための実験的な機能です。

## 入力

```fortran
&functional
 xc='hse06'
 exx_mlwf_norm_fraction=0.999d0
 exx_pair_screening='diagnose'
 exx_pair_tolerance=1d-6
/
```

`exx_pair_screening` は `off`／`diagnose`／`on`、既定は `off`。
`exx_pair_tolerance` は既定0、入力単位系に関係なく原子単位です。
**現在の占有軌道に対する交換作用行列の、格子体積で重み付けしたFrobeniusノルム誤差**を制御します。
交換混合率を掛ける前の値で、全エネルギー・力・任意軌道に対するACE誤差の上限ではありません。
WF打切り自体の誤差も別です。fraction=1で全支持の参照が取れます。

正のomegaを持つHSE06、Γ点、空間分散nativeメッシュ経路が対象です。
`exx_mlwf_norm_fraction > 0` が必要で、既存の静的SCF／固定イオンRT、restart等の制限を引き継ぎます。
PBEhや移動イオンMDへはこの省略を適用しません。

## 診断の根拠

占有数で重み付けした、必要に応じて球外をゼロにしたソースをq、局在化したターゲットをtとし、
対密度をrho=conjg(q)tとします。作用は -q C rho です。
Cは実装のFFT正規化そのままの `F^-1 diag(v_G) F` で、G=0も含めます。

Nを全格子点数、dvを格子体積とすると、次の3つの上限の最小値を用います。

|上限|使用する情報|
|---|---|
|max(abs(q)) × max(abs(v_G)) × norm_dv(rho)|離散畳み込みの作用素ノルム|
|norm_dv(q) × mean(abs(v_G)) × sum(abs(rho))|離散カーネル要素の上限|
|norm_dv(q) × sqrt(mean(abs(v_G)^2)) × sqrt(sum(abs(rho)^2))|離散カーネル1行の二乗ノルム|

連続空間のerfcをMLWF中心間距離に掛ける近似ではありません。SRとWFの裾は上記の離散量に入ります。
ノルムや係数の集約のみで、全波動関数の集約は追加していません。
平方でアンダーフローする極小対密度はL1の上限へ戻し、有限な裾をゼロと誤認しないようにしています。

1対への配分は `tolerance / (2 × Nsource × sqrt(Ntarget))`。
省略候補の上限をソースについて加算し、ターゲットについて二乗和平方根を取ります。
したがって生の省略作用の上限はユーザー予算の半分以内です。空の軌道担当もMPI集約に参加します。

## HermiticityとACE

小さい対を個別に省くだけでは、ACE入力の射影行列が非Hermitianになる場合があります。
実際、初期検証ではそのままの省略をACEが全て拒否しました。
そこで元の軌道Psiへ作用Wを回転して戻した後、次を計算します。

- G = Psi† Psi、A = Psi† W（内積にはdvを含む）。
- D = Psi G^-1 (A† − A)/2。
- WをW+Dに補正すると、Psi†(W+D)はHermitian。

G=Iを仮定せず、正定値連立方程式を解きます。Dのノルムを空間・軌道分散の両方向で集約し、
**省略上限＋実測補正ノルム ≤ ユーザー予算**を確認してから採用します。
補正予算超過・特異なG・ACEのHermitian／正定値検査失敗では、その更新を省略なしで再計算します。
ACE検査の許容誤差は緩めていません。最終ACEはHermitianな負半定値演算子です。
上限は丸め誤差を除く現在の占有作用についてのもので、ACE圧縮後の任意ターゲットや長時間RTの誤差は別途検証が必要です。

`EXX_PAIR mode/candidates/skipped/action bound/max rank CPU seconds` は試行段階の値です。
後続の `unscreened ACE fallback` と `accepted action bound` を見て採用の成否を区別してください。
CPU時間は判定だけのランク最大CPU時間で、FFT・ゲージ回転・補正・ACE・全体の実時間は含みません。

## Uの保持とRT更新

RTで既に収束した局在状態を現在の占有空間へ輸送できた場合、再最適化が失敗しても輸送したUへ戻します。
未収束試行のstatusはログに残し、`retained accepted transported gauge` を別に出力します。
これにより、再最適化の成否だけで99.9%支持と全支持が往復する挙動を防ぎます。
最初の局所化や輸送に失敗し、利用できる局在状態がない場合、有限支持のRTは明示的に停止します。
SCFの初期全支持期間は維持しています。支持半径の毎更新による変動までは固定していません。

## 検証結果

詳細な入力・ログ・実測値は同梱の検証データを参照してください。

- 小さな対密度の試験：MPI1/2/4、omega=.11/.22、全領域／局所FFTで、省略誤差が上限内。
  補正予算超過時には作用を変更せず拒否し、採用時にはACE補間を満たします。
- 空間・軌道分散の9配置、3カーネル（omega=0/.11/.3）の交換回帰。
  HSEの18配置では、空のソース／ターゲット担当を含む診断・全対省略の集約も確認します。
- native HSE SCF／16ステップRT：off／diagnose／on、fraction=1／.999、MPI1／2を比較。
  意図的に緩い予算1 a.u.のストレス試験では、RTの各更新で4対中2対、計66対を省略して採用。
  これは実用精度の推奨値ではありません。SCFの1e-6予算では基準とのエネルギー差は約1.1e-8 eV。
- 全支持HSE RTのエネルギー幅は、offの4.20e-13 Haに対し緩い予算で省略を採用したonは9.07e-11 Ha。
  fraction=.999ではoffが2.788e-6 Ha、onが2.783e-6 Ha。WF支持の近似誤差は残り、長時間精度の合格とはしていません。
- 以前エネルギーが跳んだPBEh 4×4×1/MPI8では、同じ初期状態・同じ1e-7 MLWF許容誤差で、
  幅が2.895e-4→2.975e-7 Haへ減少。33更新全てで支持が有効、5回の再最適化失敗でUを保持しました。
  従来の1e-7 Ha基準はまだ超えています。MPI1は元の初回MLWFが未収束のため、修正後は開始時に停止しました。

波動関数の局所性とSRを計算量削減へつなぐ第一段階です。厳しい予算では上限が保守的で候補が出ない場合もあり、
FFTの削減より診断・補正の費用が大きい可能性があります。高速化・弱スケーリングの改善はまだ結論していません。
