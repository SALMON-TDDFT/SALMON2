# PBE予備SCFからハイブリッドへ切り替える計算

HSE06、PBEh40、PBEh40+rVV10にPBE予備収束を追加した。
さらに、DC-SCFは既定で追加のMLWF局所化を行わず、バッファー付きフラグメント全域で交換を計算する。
`yn_exx_dc_mlwf='n'` が既定値であり、最適化・Uの追跡・軌道打切りを省く。
ACEと空間・軌道分散は維持する。通常の全体系SCF・RTでのMLWF利用は変更しない。
初期ポテンシャルからPBE交換・相関のみを使い、この段階ではEXX、ACE、MLWF、rVV10を評価しない。
指定した密度残差を指定回数連続で下回った後に目的の汎関数へ切り替える。
切替時に局所ポテンシャルと最初のEXX/ACEを構築し、混合履歴・自動混合率を初期化する。
切替をまたぐ残差は収束判定に使わない。

DCのGSでは、両段階とも指定した同じ電子温度でFermi–Dirac占有を決める。
水向けには次の300 Kを使い、コア重み付き電子数の合計を共通の化学ポテンシャルで合わせる。
PBE段階でも現在のRitz状態・固有値を更新してから占有数を決める。
この温度をレーザー励起後のRTに仮定するものではない。

```fortran
&system
  temperature_k=300d0
/
&functional
  xc='pbeh40_rvv10'
  exx_pre_scf_threshold=1d-4
  exx_pre_scf_steps=3
  yn_exx_dc_mlwf='n'
  exx_mlwf_norm_fraction=0d0
  exx_mlwf_radius=0d0
/
```

予備しきい値は選択した密度残差の単位であり、普遍的な推奨精度ではない。
既定値0では予備SCFを無効にして従来の経路を使う。
最終精度は従来の `threshold` で指定し、`nscf` は両段階の反復を含む。
予備段階のまま、あるいは本SCF未収束で反復上限に達した二段階計算は、最終GS保存前に停止する。

MLWFの勾配ノルム許容値はこれとは独立で、従来の入力既定値は `1d-6`。
以前の試験で指定した `1d-7` を必須条件にはしていない。
今回、そのノルム定義や許容値を自動変更する処理は加えていない。
DCの新しい標準経路ではMLWF自体を作らないため、この許容値は収束条件にならない。

## 検証と制限

MPI/HSE/ScaLAPACKを有効にした既存GNUビルドを使用。
H2試験の通常SCFではHSE06、PBEh40、PBEh40+rVV10でPBE段階のエネルギー列が同一となり、
切替後の最終エネルギーは直接ハイブリッドSCFと最大約1.5e-7 eVの差だった。
通常の空間分割SCFではHSE/PBEhの99.9%支持をMPI2で比較した。

300 K DCの局所化なし経路（16×8×8メッシュ、2フラグメント、各4状態）の結果:

|計算|最終エネルギー (eV)|
|---|---:|
|直接 PBEh40+rVV10、MPI2|−64.99271927395819|
|PBE→PBEh40+rVV10、MPI2|−64.99271927930923|
|PBE→PBEh40+rVV10、MPI4|−64.99271903955676|

MPI4の軌道分散も−64.99271927147012 eVとなり、差は2.5e-7 eV以内。
従来の局所化あり・全支持参照との差も2e-6 eV以内である。
k点を2点使うフラグメント経路でも局所化なし／ありの作用を比較した。

全SCF反復でコア重み付き電子数が4から1e-9以内であることも検査する。
初期状態のコア重みを含めて十分な空状態が必要であり、不足時は既存の容量検査で停止する。

**旧DC局所化経路の探索結果（新しい標準経路では使わない）:**
同じ小セルで直接計算は1000反復後の密度残差1.19e-7、二段階計算は8.39e-6となり、
最終条件1e-10を満たさなかった。二段階計算は27反復目にハイブリッドへ切り替わり、
最終未収束ガードで停止した。大セル・空状態を含む直接計算でも局所化未収束を確認した。
これらは切替の成功・速度改善を示す結果には数えない。
有限温度の空状態を含む局所支持の安定性は、別途改善・検証が必要。
そのためDC-SCFの標準経路は追加の局所化・打切りを行わない。
`exx_mlwf_norm_fraction=0` または `1` は全支持として受け付け、0と1の間や固定半径、
対スクリーニングは拒否する。旧経路を比較する場合だけ `yn_exx_dc_mlwf='y'` を指定する。
空間分割ではU行列・追跡用波動関数を保持せず、占有数の平方根を掛けた交換ソースを直接作る。
k点経路でもゲージ最適化・追跡を省き、既存のフーリエ変換・周期像の和を維持する。

初期対応は新規・固定イオンSCFと密度混合。DCでは正の電子温度を要求する。
段階を記録できない再開・チェックポイント・時間打切り・診断スナップショット、
構造最適化/MD/RTへの予備SCF指定は非対応として入力時に拒否する。
収束済みハイブリッドGSの通常の再開データ出力は可能で、RT入力では予備SCF設定を外す。
巨大系の弱スケーリング、力、長時間RT精度や速度改善は今回の試験からは結論しない。

最終検証は新規SCF・既存入力・HSE SCF/16ステップRTの30試験と、既存の局所支持SCFの4試験が成功。
MPI1/2/4の境界検査付き単体試験では、局所化なしソースの占有数重み、U・追跡配列が不要なこと、
既存のゲージ処理の維持を確認した。独立レビューで見つかった占有数更新と自動混合履歴の問題は修正済み。
