# 交換計算の三次元空間分割

## 方針と変更

波動関数、MLWF、支持球、交換作用は SALMON の n1×n2×n3 の Cartesian 分割を維持する。Γ点の共通交換経路（HSE/PBE0/PBEh）で x 方向分割を禁止していた入力検査・実行時検査・座標生成を修正した。直交セル・均等分割など既存の条件は維持する。複数k点の空間分割を新しく有効化する変更ではない。

`fftw_blocks` は各軸の既存 communicator 内で線分を分散した担当ランクへ送り、FFTW による一次元変換後、ただちに元の領域へ返す。保持する実空間・逆空間の配列はいずれも元の xyz ブロック配置である。波動関数や三次元の全Boxを各ランクへ複製しない。MPI通信は呼出しスレッドで行い、独立したFFT線はOpenMPで処理する。新経路の時間内訳は `fftw_block_seconds`（準備、FFT、通信、詰替え）で計測できる。

軸の全長を L、軸 communicator のランク数を P、局所領域の横断線数×バッチ数を Q とすると、一時配列各々は L×ceil(Q/P) 複素数。局所作業量に線数の端数分が加わる。3軸分のキャッシュを保持する。全領域経路の交換対バッチ数は従来どおり4。

局所経路では、MLWF支持内のデータ、または必要な離散カーネル変位を保持するランクから subgroup を作る。小箱・局所FFT作業配列はこの subgroup 内でのみ保持する。無関係なランクへ小箱を複製しない。ただし subgroup 内では小箱の複製があり、支持範囲のメタデータ集約と communicator の分割は全空間ランクで行う。通信すべてが近傍通信になったわけではない。

離散カーネル、G=0、周期境界、局所畳込みのpadding、支持率/R指定の意味は変更しない。支持が広く局所FFTが有利でない対には、元の三次元分割に戻る軸FFTを使う。旧2次元インターフェースは参照試験・他の呼出し側との互換性のため残している。

## 検証

- FFT：MPI1/2/4/8、OMP1/2、8×1×1・2×2×2・1×2×4。解析的平面波と往復変換の誤差は約8e-16以下。
- 24×10×6格子・8×1×1：線数がランク数で割り切れない場合、バッチ数3→1→0→3。
- 15×8×6格子・3×2×1：旧ペンシル法では必要だった他軸の割り切りを要求しないことを確認。
- HSE/Coulomb交換：全領域・局所支持の両方を従来の逐次参照と比較。周期境界と分割境界を跨ぐ支持を含み、差は約2.2e-17以下。
- 既存の局所FFT/バッチバックエンド、対選別、Γ点MLWF試験を実行。
- 標準CTest `438_H_pbe0_mesh_rt_x` を追加。PBE0 DC→RTのx分割と既存y分割の電流・エネルギーを比較。関連fixtureを含む8テスト通過。
- GNU MPI/ScaLAPACKビルド、MPIなしビルド、MPIなし実行、追加FFTモジュールのOpenMPなし実行を確認。
- Si 8セル、同じHSE06 GSからMPI8×OMP2で16ステップ。8×1×1・2×2×2・1×2×4の全条件で完走。分割間の最大電流差2.47e-17 au、エネルギー差9.95e-13 Ha。確認中に他の試験も実行したため、この所要時間を性能比較には使わない。

ログと分割比較値は [reports/exx-block3d](reports/exx-block3d/) に保存。

## 適用範囲と次の計測

今回の変更はΓ点の交換経路を対象とする。Hartree、rVV10の既存のFFT分散方式や多k点専用経路を全面的に書き換えたものではない。NVHPC/cuFFTおよび富岳コンパイラでの実行は未検証。

旧8セルレーザー計測キューは停止し、結果を保存した。長時間比較を再開する際は、共通のnproc_rgrid=8,1,1に揃え、PBE・HSE06自動半径・HSE06 R=10 bohr・PBE0を同じ実行条件で測る。性能とメモリの改善はこの再計測で判断する。


## 2026-09-30：局所軸と全周期軸の混合

支持がセル全体を覆う軸のFFT長を元の周期長に保ち、局所軸だけを2*box-1以上へパディングする。周期軸の重複変位は同じ離散カーネル値へ写るため加算しない。球状支持、対選別、物理カーネルに新しい距離打切りは導入しない。

xに局在しy/z全体に広がる支持の試験では、修正前は局所経路が不使用になり失敗。修正後はHSE/Coulombと全領域参照の差6e-16以下で通過した。Si8セルの初期計算は8704対が局所FFTへ移り、全領域FFT対は0となった。自動半径の16ステップは修正前参照との電流差1.39e-17 au、エネルギー差は出力精度で0。

固定原子のΓ点native RTで固定Rも許可するよう入力検査を整合させた。DC-GS保存情報は、初期GSのR=0から新規RTでR>0へ切り詰める場合だけ支持半径の差を許可する。汎関数・カーネル等の照合は維持し、RT再開、GS段階の設定変更、既にR>0で保存したGSの半径変更は引き続き拒否する。固定RでのMD/構造最適化は有効化していない。

R=10 bohrのSi16ステップも完走。初期最小保持ノルム約99.873%に対して警告を出し、Rを拡大しない。標準CTest439を追加し、438と関連fixtureを合わせた11項目、およびメタデータの拒否条件試験を通過。MPIなしビルドも通過。

全周期軸のカーネル保存も0:n-1の一意な変位のみとし、局所軸だけ-(box-1):box-1を保存する。例えば全体128×16×16、支持箱31×16×16の場合、各カーネル一時配列は58,621点から15,616点へ減る（約73%削減）。これは当該配列の削減率であり、プロセス全体のメモリ削減率ではない。
