2026-09-24時点。Taylor検証時の `35bdb9fd` に加え、以下に記載する交換配列の分散保持改修を含む。このノートは実験ブランチの状態を記録するもので、SALMON本流での正式対応を意味しない。

## 物理モデルとSALMONへの接続

HSE06の短距離Fock交換25%、遮蔽パラメータ `omega=0.11 bohr^-1` と、対応するLibxcの半局所部分を使用する。交換核の逆空間表現は

$$v_{SR}(q)=\frac{4\pi}{q^2}\left[1-\exp\left(-\frac{q^2}{4\omega^2}\right)\right],\qquad v_{SR}(0)=\frac{\pi}{\omega^2}.$$

一スピンの占有軌道を交換源として使う。核ルーチン自身には混合率0.25や余分なスピン係数を入れず、SALMON側の作用・エネルギー組み込みで係数を整合させる。SCFとRTで同じ交換作用を用いる。全エネルギーでは、固有値期待値に含まれる交換寄与を調整して二重計上を避ける。

## 交換計算、MPIとACE

全交換作用では、占有源から密度行列の行ブロックを `ZGEMM` で作り、均一kメッシュに対するFFT、短距離核との積、逆FFT、対象軌道への `ZGEMM` を実行する。位相とk点順序を明示的に扱い、シフト・並び替えを含む小系で独立Python実装との一致を検証している。

MPIは現在k点分割のみ。源・対象・作用・位相・ACE因子を担当k点で保持する。密度行列の小ブロックだけをk担当から行担当へAlltoall転送し、FFT・核との積・逆FFTの後にk担当へ戻して対象軌道へ作用させる。全k点の軌道配列を全ランクへ集約する経路は廃止した。OpenMPとBLASのスレッド数は計測では各1とした。

占有軌道を $U$、全交換作用を $W=KU$ とすると、ACEは $M=-U^\dagger W$ を対角化し、その逆平方根を用いて因子 $B$ を構築する。積分重みを含めた作用は $K_{ACE}X=-B(B^\dagger X)$。占有構築部分空間で全交換を再現し、任意の試行ベクトルには圧縮作用を与える。正定値性・条件数を検査し、不適切な構築を拒否する。

現コードのループ構造から、空間点数G、k点数K、占有数N、対象軌道数Tに対し、全交換更新の主要演算量は概ね `O(G² K (N+T+log K))`。ACE作用は `O(G K N T)`、構築には小行列の対角化等が加わる。これは実装構造からの見積もりで、k点増加の実測ではない。源は概ね `O(GNK/P)`（PはMPI数）に分散した。一方、作業領域 `O(bGK)`（bは行ブロック幅）、パディングを含む送受信領域、サンプル核の複製は残る。MLWFの局所打ち切りによる線形スケーリングは実現していない。

## ACEで実際に行っている処理

ACE（Adaptively Compressed Exchange）は、**高価な非局所Fock交換の作用を、占有軌道から作る低ランク演算子で繰り返し評価する処理**である。密度や軌道を局所化する処理でも、交換を局所ポテンシャルに置き換える処理でもない。現在のネイティブ経路ではMLWF変換を必要としない。

### 1. 更新時には全交換を計算する

各k点の占有軌道を列に並べた行列を $U_k$ とし、全k点の占有状態が決めるFock演算子を $K[U]$ とする。`hse_refresh` は全交換核で

$$W_k=K[U]U_k$$

を計算する。この高価な計算はACEを使っても必要である。ここでの $K$ はHSE混合率0.25を掛ける前の交換演算子。交換エネルギーも、この全交換作用 $W_k$ と占有軌道から評価する。

### 2. 各k点で圧縮因子を作る

格子積分重みを $dV$ として、占有数×占有数の小行列を作る。

$$M_k=-dV\,U_k^\dagger W_k=Q_k\Lambda_k Q_k^\dagger,\qquad
B_k=W_kQ_k\Lambda_k^{-1/2}.$$

`hse_ace_build` は `ZGEMM` と `ZHEEV` を使う。Hermitian性を確認して丸め誤差を対称化し、最大固有値が正でない場合や最小固有値が最大の `1e-12` 以下の場合は失敗させる。小さい固有値を削除して先へ進む実装ではない。通常の因子 $B_k$ は実空間点数×占有軌道数であり、全実空間点数の二乗の交換行列を保存する必要がない。

### 3. 試行ベクトルには二つの行列積で作用させる

任意の対象軌道行列 $X_k$ に対し、`hse_ace_apply` は

$$C_k=dV\,B_k^\dagger X_k,\qquad K_{ACE,k}X_k=-B_kC_k$$

の二つの `ZGEMM` を実行する。この作用のたびに全交換のFFT・核との積をやり直す必要はない。Hamiltonianへの追加時に0.25を一度掛ける。作用時には担当k点の因子だけで計算できる。

### 4. 何が厳密で、何が近似か

構築に使った占有部分空間では、数値丸めの範囲で

$$K_{ACE,k}U_k=W_k=K[U]U_k$$

を再現する。ただし、固定したACEは任意の未占有方向やTaylorの $HU,H^2U,\ldots$ 全体に対して厳密ではない。また、占有源が変わった後の新しいFock演算子も、古いACEだけでは再現しない。そのため更新と全交換による監査が必要になる。ACEは新しい物理的な遮蔽モデルではなく、同じHSE交換の数値的な圧縮である。

### 5. いつ作り直すか

| 経路 | ACEの扱い | 全交換による確認 |
|---|---|---|
| SCF・通常の交換更新 | 新しい占有源から $W$ と $B$ を再構築 | 更新時に全交換作用・交換エネルギーを評価 |
| Taylor予測段 | 開始時のACEを固定し、Taylor試行ベクトルに作用 | 開始状態の構築時に全交換を使用 |
| Taylor修正段 | 予測状態からACEを再構築し、開始時と予測時の**演算子**を平均 | `hse_taylor4_full` との独立比較で試行方向の近似誤差を測定 |
| Taylor受理後 | 受理状態の通常の密度・XC更新でACEを再構築 | 次のステップの源を受理状態へ戻す |
| PT-CN内側反復 | ACEのみ固定して繰り返し作用。密度・局所ポテンシャルは試行状態に応じて更新 | この内側の収束だけでは受理しない |
| PT-CN外側反復・受理判定 | 試行終点を新しい占有源として全交換・ACEを更新 | 終点自身は新ACEの構築部分空間に入るため、全交換と一致する作用でCN残差を再評価 |

同一の源が全MPIランクで要素ごとに完全一致する場合のみ、`hse_refresh` はキャッシュを再利用する。固定ステップ数ごとの間引き更新や、近い源なら再利用する許容誤差判定は現在入れていない。PT-CNの論理的な更新要求数と、実際の全交換計算回数はこのキャッシュにより異なる場合がある。

Taylorの平均因子は $[B_{old},B_{pred}]/\sqrt{2}$ なので通常の2倍の列数になるが、作用は正しく $(K_{ACE,old}+K_{ACE,pred})/2$ となる。`hse_taylor4_full` では各試行ベクトルに圧縮作用を使わず、保存した源から全交換を作用させる。ただしこの監査経路も通常の更新時にACEを構築するため、計測した全交換版にはその費用が残る。

**高速化の理由は、全交換をゼロにすることではなく、同じ交換源を使う多数の作用を二つのBLAS積で代替すること。** 実測でTaylorは7.41→1.53秒/stepとなった一方、PT-CNでは全交換更新が依然として支配的だった。構築部分空間外の誤差は、別掲の全交換比較と時間刻み収束で評価している。

## 時間発展

### Taylor 4次＋予測子・修正子

`propagator='hse_taylor4'`, `n_hamil=4`, `yn_predictor_corrector='y'`。

既存の [taylor.f90](../src/rt/taylor.f90) 自体は変更していない。ステップ開始時の交換源を保存し、予測状態から更新した局所・交換演算子と開始時の演算子を平均して修正段を進める。TaylorのHの累乗を作る試行ベクトルを占有交換源として使わない。

ACEの平均は因子をそれぞれ `1/sqrt(2)` 倍して連結し、`(K_old+K_predicted)/2` を表す。軌道そのものの平均ではない。監査用の `hse_taylor4_full` では同じ方法で源を連結し、全Fock演算子を各試行ベクトルに作用させる。

指数関数の多項式が4次でも、今回の自己無撞着ポテンシャルの予測子・修正子を含む時間精度は概ね2次。実測の電流収束次数は1.991である。

### Parallel-transport Crank–Nicolson（PT-CN）

`propagator='hse_ptcn'`。占有部分空間の不要な回転を除いた勾配を用い、CN方程式を自己無撞着に解く。内側ではACEを固定して前処理付き反復を行い、外側で全交換を更新する。最後に新しい全交換で終点残差を評価し、相対残差 `1e-10` 未満を要求する。非線形残差が小さくても時間離散化誤差が消えるわけではない。

HSE軌道の強制的な再規格化は行わない。PT-CNの残差・ノルム判定とTaylorの検証を混同しない。TaylorはCN残差試験を持たず、時間刻み収束、電子数、直交性で評価する。再開には `hse_restart.bin` を保持し、刻み・場・系・占有・擬ポテンシャル等の互換性を検査する。

## 精度の確認

Si8、32電子、占有16軌道、12³実空間格子、4³ k点、同一初期軌道、z方向impulse `1e-4 au`。k点収束は行っていない。

- 0.1935 fs：Taylor dt=0.04を基準とした電流RMS差はTaylor dt=0.16で0.01057%、PT-CN dt=0.32で0.25421%、dt=0.08で0.01656%。
- 0.774 fs：Taylor dt=0.08に対するPT-CNの電流差はdt=0.32で0.473%、dt=0.16で0.149%。誘起密度差は4.31%、2.93%で、密度まで同精度とは未確認。
- 全交換とACEのTaylor比較（同じdt=0.16、0.1935 fs）：電流差0.007109%、誘起密度差0.003575%。
- Taylor＋ACEのdt=0.32は電子数チェックで停止した。安定な小さい刻みで比較する。
- Taylorの連続実行と途中再開はbitwise一致。79件の数値テスト、6件のSi/TDCDFT回帰テストが通過し、HSE有効・無効のビルドを確認した。

電流は共通時刻で直接比較し、波動関数は占有ゲージを整合させて比較した。誘起密度誤差の分母は大きな全密度ではなく `rho(t)-rho(0)`。これらはサブfsの積分法検証であり、励起子ピークの一致を示すものではない。[精度データ・入力・図](results/si-hse-taylor/README.md)。

## 計算効率と選択

**以下の速度表は分散保持改修前の測定。** 最新の分散版ではメモリを約35–58%削減した一方、同条件の短時間計測では約22–39%遅くなった。[変更前後のメモリ・時間](results/si-hse-distributed-memory/README.md)を合わせて参照する。

Apple M5 Pro、MPI8、同じ初期状態から5ステップ×2回を順番に測定。別のPython MPI8参照計算は背景で継続しており、専有環境の測定ではない。秒/stepはRTループ時間（出力含む、初期化除く）。1 fs費用は短時間測定からの換算である。

| 方式 | dt (au) | 秒/step | 分/物理1 fs |
|---|---:|---:|---:|
| Taylor＋ACE | 0.16 | 1.53 | 6.59 |
| Taylor＋ACE | 0.08 | 1.51 | 13.00 |
| PT-CN＋ACE | 0.32 | 3.19 | 6.86 |
| PT-CN＋ACE | 0.16 | 2.74 | 11.79 |
| PT-CN＋ACE | 0.08 | 1.75 | 15.05 |

Taylor dt=0.16はPT-CN dt=0.08より短時間の電流・密度誤差が小さく、同じ物理時間を約2.28倍低い費用で進められた。PT-CN dt=0.32はステップ数を減らせるが、1ステップの反復費用によりTaylor dt=0.16とほぼ同じ費用で、精度は低い。したがって現時点ではTaylor＋ACEを基準にする。ただし長時間の最適dtは未確定。

同じMPI8・dt=0.16で全交換Taylorは7.41秒/step、ACE版は1.53秒/step：**約4.84倍**。監査用全交換経路にもACE更新費用が残るため、最適化された全交換法との理論的比較ではない。

別の同条件3ステップ比較ではFortran MPI8はPython MPI8より4.68倍、Fortran MPI1より4.95倍高速だった。これらは異なる比較なので倍率を掛け合わせない。従来PT-CN計測では全交換が約1.75–1.88秒/stepを占め、ACE構築約0.012秒、ACE作用約0.14秒より大きい。今後は全交換更新を減らす・速くすることが主要課題。

PT-CNの既存メモリ観測はランクRSS合計約2.31 GiB。ピークでも共有ページを除いた実メモリでもなく、Taylorとの同条件比較は未実施。[反復計測の全データと損益](results/si-hse-taylor/COSTS.md)、[Fortran/MPI検証](results/si-hse-native/README.md)。

## 現在の制限と再現方法

CPU、固定イオン、非磁性・完全占有スピン対、立方等間隔実空間格子、完全な立方均一kメッシュ、k点MPI分割を対象とする。NLCC、SOC、DFT+U、分数占有、実空間/軌道MPI分割等は未対応。ネイティブHSE RTは横方向impulseに限定し、レーザー・pump–probe HSEは未対応。TDCDFT側のpump–probe対応と混同しない。

`USE_HSE=ON`, `USE_MPI=ON`、FFTW、Libxc Cライブラリ、BLAS/LAPACKが必要。HSE無効ビルドに新しい依存を課さない。[ビルド・入力・再開手順](../samples/hse_native/README.md)から再現できる。

TDCDFT・ELFなどの既存機能は[別の検証ノート](tdcdft-validation.md)を参照。このノートのHSE性能測定を、MLWF局所打ち切りやTDCDFTの速度評価と解釈しない。

## 固定Si系の強スケーリング

[競合する参照ジョブを停止したMPI1/2/4/8/16測定](results/si-hse-strong-scaling/README.md)を追加した。Taylor＋ACEは1→16並列で5.05→1.27秒/step（3.96倍）、最大ランクRSSは597→175 MiB、合計RSSは0.583→2.500 GiB。この小系では8並列が速度と合計メモリのバランスを取りやすい。

## BLAS内部OpenMPとTaylor4＋ACE

[BLAS内部OpenMP計測](results/si-hse-blas-hybrid/README.md)を追加。HSEのBLAS呼び出しはSALMONのOpenMP領域外で行い、BLAS内部の並列化に委ねる。ACE適用は各k点について `overlap = dv * factors† * target`、`action = -factors * overlap` の二つのZGEMMであり、k点ループ自体は直列。交換カーネルの要素積・転置用整形にはSALMON側OpenMPを使う。MPIとFFTWは並列領域外。スレッドごとの巨大な軌道複製は行わない。

富岳でOMP約12を使う構成を想定し、OpenBLAS固有の1スレッド強制を廃止した。リンクするBLASの並列版と実行時設定が必要。ローカルOMP12の数値一致と富岳実機の性能検証は区別する。

## Siのz偏光対称性

[対称性縮約の実装と検証](results/si-hse-symmetry/README.md)を追加。波動関数・ACEを既約点で保持し、交換用の密度タイルを対称操作から再構成する。16³の既定シフト格子は4096→576点。完全格子FFT・一時配列が残るため、総メモリや交換時間の一律1/8削減は主張しない。TDCDFTは固定α・z偏光に限定。対称性を含めたcheckpoint整合性を検査する。
