# Si：z偏光での対称性縮約

Taylor4＋ACEのHSE06と固定αTDCDFTに対称性を追加。Si慣用胞を対象に、z方向を保つ8種類の回転・鏡映と4種類のFCC並進を組み合わせた32個の空間操作を使う。8操作だけでは慣用胞の整数並進を法として閉じず、一般の密度や射影子を正しく平均できないため採用しない。

## k点と保持メモリ

既定の半格子シフト、境界上の重複を含めた正確な点数：

| 完全格子 | 全k点 | 既約k点 | 点数削減 |
|---|---:|---:|---:|
|4³|64|12|5.33倍|
|16³|4096|576|7.11倍|

一般位置のstarは8点。鏡映面上は4点なので、16³も厳密な512点にはならない。
波動関数とACEは既約点だけ保持する。Si8・16占有軌道・12³実空間格子なら、波動関数1組の合計サイズは16³全格子で1.6875 GiB、既約格子で0.2373 GiB。これは総RSSではない。

HSE交換は完全格子の畳み込みを保つ。各rankに属するstarだけを再構成し、little groupの変換後射影子を等重みで平均する。軌道のゲージを直接平均しない。並進位相と逆格子折り返しの位相を含む。変換されたsourceは1操作ずつ作業配列に入れて密度タイルに加算するため、32操作分の軌道を複製しない。代表点の交換作用だけでACEを構築し、交換エネルギーには既約点の重みを使う。

ただし、全k点のFFTW作業領域・通信タイル・一時target/action配列が残る。各タイルごとの対称変換も費用が大きく、HSEの時間・総メモリが1/8になる実装ではない。Macでの16³本計算の容量・時間は未測定。

## 検証

- Bloch位相、分数並進、little-group射影平均を独立式と比較。
- 展開済みsourceでの交換と、密度タイルcallbackでの交換の最大相対差5.08e-16。
- 独立MPI交換テスト合格。不均等なstar担当数でも交換作用を検証。
- 途中2ステップから再開したHSE/TDCDFTは連続4ステップと最終軌道がbitwise一致。
- 同じ収束済み全格子基底状態から代表軌道を取り出し、完全64点対既約12点を比較。dt=.08 a.u.、z impulse=1e-4、4ステップ。
- HSE06のJz相対差1.60e-8、固定α=.2、β=0、γ=.001 TDCDFTのJz相対差3.28e-7。

完全格子はMPI4、既約格子はMPI3として不均等star分割も確認。初期SCF状態の有限精度と対称化による差を含む。短時間・有限格子の検証であり、スペクトル収束の証明ではない。別の長時間計算が同時実行中なので、`parity.json`のRT時間は性能比較の基準にしない。HSEの交換再構成は今後の高速化対象。

## 使用条件と再現

`samples/exercise_si_symmetry/sym.dat`を実行ディレクトリに置き、`&system`に `yn_symmetry='yyn'` を設定する。k格子は全格子の値（例えば16,16,16）を指定する。基底状態も同じ対称群・既約点で用意する。全格子のcheckpointをそのまま縮約計算に読ませない。

現在の対象は固定イオン・z偏光。TDCDFTは `tdcdft_screening='none'` に限定。外部ファイルの場は未対応。対称操作の群としての閉性、Cartesian等長性、整数格子写像、元素を保つ原子置換、外場方向を検査する。HSEは立方セル・立方格子・整数グリッド写像など既存の制約を維持する。

再開時は `symmetry_restart.bin` にk点・重み・群を保存し、変更や欠落を拒否する。対称性なしの従来checkpointは引き続き使用可能。

任意のローカル検証は `prepare_native_validation.py` と `run_native_validation.py --executable /path/to/salmon`。既存の収束済みSi参照データを必要とする。これらは対称性縮約の確認用で、16³の基底状態を生成する道具ではない。

HSE有効・無効の両構成でビルド成功。ネイティブテスト7件成功（実MPIの1件は通常スイートでskipし、別途有効化して成功）、対称群・checkpointテスト5件成功。独立コードレビューで指摘された非等長操作の受理を修正し、具体的な反例の拒否テストを追加した。
