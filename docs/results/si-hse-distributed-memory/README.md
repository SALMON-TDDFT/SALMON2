# HSE交換の分散保持とメモリ測定

2026-09-24。比較元は `e8793dd3`。全k点の占有源・対象軌道・交換作用を各ランクへ複製していたネイティブHSE経路を改修した。物理的な交換核、ACE近似、時間発展法は変更していない。

## 保持・転送するデータ

- 占有源、対象軌道、交換作用、位相、ACE因子、厳密一致判定用の源キャッシュは**担当k点のみ**保持する。
- 全交換は、担当k点で密度行列の行ブロックをBLASで作る → `Alltoall` で行担当へ転送 → k方向FFT・核との積・逆FFT → `Alltoall` でk担当へ戻す → 担当k点の対象軌道へ作用、という順序。
- 交換作用の全k点配列を作って全ランクに還元する処理を削除した。
- Taylorの初期・中点ACE因子と交換源は使用終了直後に解放する。全交換Taylorでは未使用の初期・中点ACE因子を作らない。
- 小さなk順序表とサンプル済み交換核は複製する。行担当がk方向FFTを行うため、**一時的な行ブロックには全k点分が必要**。分散FFTを導入した実装ではない。

空間点数G、占有数N、k点数K、MPI数Pに対し、軌道配列は概ね `O(GNK/P)`。ブロック幅bのFFT作業領域は `O(bGK)`、送受信は各 `O(bG ceil(K/P) P)`。不均等分割はパディングを使う。現在bは `max(1,min(16,64/P))`（整数除算）、MPI8で8。Pが大きくb=1となった後は作業領域はこれ以上1/Pには縮まらない。核の `O(GK)` 複製も残り、全メモリの理想的な1/Pスケーリングを主張しない。

## 実測

Si8、12³実空間格子、4³ k点、MPI8、OpenMP/BLAS各1スレッド。各方式5ステップ、旧版・新版を順番に実行。Apple M5 Pro。別のPython MPI8参照計算は背景で継続。

| 方式 | dt (au) | 旧・合計RSS (GiB) | 新・合計RSS (GiB) | 削減 | 旧→新 秒/step |
|---|---:|---:|---:|---:|---:|
| Taylor＋ACE | 0.16 | 2.20 | 1.39 | 36.8% | 1.51→2.09 |
| PT-CN＋ACE | 0.32 | 2.31 | 1.50 | 34.9% | 3.20→3.91 |
| 全交換Taylor監査 | 0.16 | 3.47 | 1.47 | 57.6% | 7.74→10.11 |

RSSは `ps` で要求間隔0.1秒（実際は収集時間が加わる）ごとに観測した、8ランク同時合計の最大値。共有ページは重複計上され得る。保証されたピークや固有物理メモリではない。秒/stepはRTループ時間を5で割った値で、初期化を除き、出力・チェックポイントを含む。背景負荷と短い測定区間のため、小差を一般化しない。

**メモリ削減の代わりに、今回は通信費用が増えた。** 所要時間はTaylorで約39%、PT-CNで約22%、全交換監査で約31%増加した。全軌道の複製を保持していた旧版の速度を、新版の速度として引用しない。実装・効率ノートの従来表は旧版測定として残す。

最初に試したb=2ではさらに省メモリだったが、Taylorで約2倍遅くなった。b=8に拡大して集団通信の回数を減らした。試行値も `measurements.json` に保存している。

## 数値・再開の検証

- 独立Python全交換との一致：シフト・並び替えk点、任意の対象軌道、MPI1/3/8、不均等k点分割、部分行ブロック、空の行担当を検証。
- ある1ランクだけの不正形状・NaN入力も、全ランクがエラーを返して終了することを実MPIで検証。
- Siの5ステップ：最終版と旧版の軌道相対差は最大1.78e-14、電流最大差は4.23e-17 au未満。差はBLASブロック分割変更による丸め誤差の範囲。
- 初期b=2の試行では同じ5ステップの軌道・電流はbitwise一致。これを最終b=8のbitwise一致と混同しない。

MPI8に対する2ステップの軌道相対差はMPI1で5.03e-12未満、MPI4で3.22e-12未満。2ステップ＋途中再開3ステップは連続5ステップとbitwise一致した。結果は `integration_checks.json` に記録した。既存Si/TDCDFTの6件の回帰テストも通過。通常の数値テスト79件と、別実行の実MPI交換テストが通過。メモリ計測は上記Si条件のみで、k点収束や大規模系のスケーリング試験は行っていない。

## 再現

[ビルド手順](../../../samples/hse_native/README.md)で旧版・新版の実行ファイルを別々に用意する。[比較入力](../si-hse-taylor/inputs/)の `compare_hse_taylor4_dt0.16`、`compare_hse_ptcn_dt0.32`、`compare_hse_taylor4_full_dt0.16` を `calculations/si_hse_native/` 以下の対応ディレクトリの `inputfile` として配置し、共通の `reference_restart` を準備する。入力内の擬ポテンシャル絶対パスは実環境に合わせる。

```sh
python3 samples/hse_mlwf_reference/benchmark_distributed_memory.py \
  --before /absolute/path/to/old/salmon --after /absolute/path/to/new/salmon
SALMON_TEST_MPI=1 python3 -m unittest discover \
  -s samples/hse_mlwf_reference -p test_native_distributed_exchange.py
```

計測スクリプトはmacOSの `ps`、MPI8、5ステップを使い、対象プロセスの子孫のみを集計する。`memory_old_*` / `memory_new_*` は計測用ディレクトリとして出力を更新する。測定データと実行ファイルのSHA256は [measurements.json](measurements.json) に保存した。

## 固定Si系の強スケーリング

[競合する参照ジョブを停止したMPI1/2/4/8/16測定](../si-hse-strong-scaling/README.md)を追加した。Taylor＋ACEは1→16並列で5.05→1.27秒/step（3.96倍）、最大ランクRSSは597→175 MiB、合計RSSは0.583→2.500 GiB。この小系では8並列が速度と合計メモリのバランスを取りやすい。
