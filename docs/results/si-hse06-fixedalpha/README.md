# HSE06とα固定TDCDFTのimpulse誘電関数比較

状態：HSE06・固定αTDCDFTとも正常終了。21.286 fsの比較スペクトルを生成・点検済み。

Si8、32電子、10.26 bohr立方セル、12³格子、4³ k点、同一Si擬ポテンシャル。
z方向の外部A/cステップ +1e-4 a.u.。K点収束計算は行わない。
各汎関数の自己無撞着基底状態から開始する。

- HSE06：Taylor4＋ACE、dt=0.16 a.u.、5500ステップ。
- TDCDFT：PZ基底状態、α=0.2固定、β=0、γ=0.001 a.u.、Proca、遮蔽更新なし、dt=0.08 a.u.、11000ステップ。
- 共通観測時間880 a.u.（21.286 fs）。440/660/880 a.u.の窓依存性も比較。
- 既存の検証済み `samples/exercise_si_tdcdft/analyze.py` の電流規約と三次窓関数を使用。
- Re ε、Im εを同じエネルギー軸で表示。追加のシザー補正・減衰なし。

有限窓のピークを自動的に束縛励起子と解釈しない。基底状態のバンド構造の差も含む比較であり、長時間のdt収束やACE近似誤差を確定するものではない。

計算ディレクトリ：`calculations/si_hse_native/impulse_hse06_fixedalpha` と `impulse_tdcdft_fixedalpha`。
各 `status.txt` と `run.log` が状態。1000ステップごとにcheckpoint保存。
停止したPython時間発展計算は再開していない。Fortran計算のみ。

## 21.286 fsでの結果

| モデル | 2–4 eV内の最大 | 4–6 eV内の最大 |
|---|---:|---:|
| HSE06 | 3.88 eV | 4.30 eV |
| 固定α TDCDFT | 3.35 eV | 5.32 eV |

440/660/880 a.u.の窓でHSE低側最大は3.81/3.84/3.88 eV、TDCDFTは3.32/3.34/3.35 eV。これは有限窓の区間最大値であり、励起子束縛エネルギーではない。低周波側のIm εには大きな負成分があり、有限窓・DC成分・電流規約の影響を追加検証するまで静的誘電率を解釈しない。元の全域図と数値を保持する。
