# 初期MPI/OpenMP比較（BLAS内部1スレッド固定）

この履歴データは、OpenBLASの内部スレッド数をAPIで1に固定した中間実装。
最終実装はこの固定を廃止したため、現在のコードで同じ環境変数だけを指定しても同条件にはならない。
現行の測定は [BLAS内部OpenMP](../si-hse-blas-hybrid/README.md) を参照。

Si、4³ k点、12³格子、Taylor4＋ACE、dt=0.16 a.u.、5ステップ×2回。
MPI bindingなし。合計RSSは観測ピークの最大値。

| MPI×OMP | 平均 秒/step | 合計RSS GiB |
|---|---:|---:|
|16×1|1.25545|2.524|
|8×2|1.33303|1.396|
|4×4|1.61042|1.044|
|8×1|1.40366|1.390|
|4×1|2.01070|1.041|

軌道相対差は最大3.29e-12。Taylor再開のbitwise一致、PT-CNのOMP2/4相対差は `validation.json`。
2回のみの短時間測定であり、小さな速度差は断定しない。
