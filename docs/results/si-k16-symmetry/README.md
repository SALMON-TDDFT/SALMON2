# Si 16³ 対称性容量試験

4³のHSE/TDCDFTが正常終了した後に開始。全4096点、既約576点、32空間操作。Si8、12³実空間格子、16占有軌道。MPI4×OMP4、64 GiB Mac。既存4³checkpointは流用しない。

実行中の状態：`calculations/si_hse_native/k16_symmetry/status.json`。
制御ジョブ：同ディレクトリ `run_pilots.py`（実行セッション61414）。重複起動しない。

1. 16³ PZ基底状態を新規SCF。収束しない場合は後続を実行しない。
2. 固定α=.2、β=0、γ=.001のTDCDFTを5ステップ、dt=.08 a.u.。
3. 同じ16³のPZ軌道を初期値としてHSEのSCFを1反復だけ試行。これは未収束HSE状態であり、HSEの物理的impulse応答とは扱わない。

毎秒、全子rankのRSSを取得し、合計・rank最大を保存。合計48 GiB超または各段階6時間超で、この試験のプロセス群を停止する。RSSは共有ページを重複計上しうる観測値。初期化も監視対象。

この先はHSE pilotの容量・時間を確認してから16³ HSE基底状態を準備し、短いTaylor4＋ACEの計測を実施する。HSEの長時間impulse本計算は今回の許可範囲に含めない。自動フォローアップはまだ継続中。

## 初回結果（HSE試行は進行中）

- PZ基底状態：収束、約119秒、観測最大合計RSS 1.87 GiB。
- 固定αTDCDFT：5ステップ正常終了、0.3171秒/step、観測最大合計RSS 1.37 GiB。毎秒採取で約2秒の短い実行なので、RSSの瞬間ピークを取り逃がす可能性がある。
- 同じ速度を仮定すると21.3 fs（11000ステップ）は約58分。長時間の実測ではない。
- HSEはSCF初期化中、合計RSSは少なくとも約24.1 GiB。最終ピーク・SCF時間・Taylor＋ACE時間は未確定。
