# CC0 optical numerical subset

Ten pinned scalar n,k tables, original license and source snapshots.
Five additional optical oxide films:SiO2,Al2O3,TiO2,Ta2O5,HfO2.
89 retained fitting trials, including alternatives; no raw input changed.
Tensors use an explicitly assumed isotropic diagonal model with one independent
component when directional data are absent. This does not establish anisotropy
or general native tensor propagation. Ag uses a20-pole candidate with an explicit0.002au damping floor;
this is measured-point screening, not material-physics validation.
TiO2 optimizer budget warnings remain. See OPTICAL_DATA.md / OPTICAL_DATA.en.md.
