# SBEの状態と計算処理ハンドル

[English](SBE.en.md)

既存の`SBEInitialState`／`new_state`／`step(A)`を使います。入力はAc=A/c、
公開電流は電荷電流密度jです。`matter_current`は内部のSALMON物質電流J=−jを返します。
初期配列はバンド・k点がFortran順序で、単位は原子単位、閉殻の偶数電子数が対象です。
補正次数0〜3と非局所速度補正の有無は初期モデルで固定します。

```python
# modelは既存のSBEInitialState
with model.new_state(dt=0.02, initial_A=(0., 0., 0.)) as state:
    current = state.step([0.001, 0., 0.])
    saved = state.snapshot()
    density = state.density       # この要求時だけ密度行列を取得
    state.step([0.002, 0., 0.])
    state.restore(saved)
```

モデル行列、重み、バンド差分、占有数は初期モデルごとに一度計算処理側へ準備し、
同じモデルの複数状態で共有します。各状態は独立した密度行列・直前A・電流を持ちます。
通常のstepはA3成分を渡し、J3成分を受け取ります。全モデル行列を毎回コピーしません。
密度行列は`density`や`snapshot()`を要求したときに書き出します。

数値更新には変更していない既存のvelocity-gauge核を使い、演算順序とk点外側の
OpenMP分割を保持します。wheelのOpenMP設定を今回新たに有効化したという意味ではありません。

## モデルの読込みと数値手法

```python
from salmonpy.sbe import SBEInitialState
model = SBEInitialState.from_salmon(
    directory, sysname, bands=bands, kpoints=kpoints, electrons=electrons,
    lattice=lattice, correction_order=0, nonlocal_correction=False)
```

格子ベクトルは列です。テキストローダーは単一スピン・直交形式のk/eigen/tm出力と
明示したesp[a.u.]を読み、eVや非直交形式を拒否します。配列からの構築では右手系格子を使い、
固有値は(band,k)、行列要素は(band,band,xyz,k)です。占有はエクスポート列によらず最初のelectrons/2バンドに2ずつ。
active_bandsを省略すると全バンドを使います。
4次Taylorの4項を中点Aで順に加え、端点Aで電流を計算します。厳密ユニタリ化、可変dt、
ノルム補正は追加していません。dt・バンド数・k点・モデル自体の物理的妥当性は別途確認してください。
長さゲージや励起状態の外部restart読込みは未対応で、この初期ローダーはGS密度を作ります。

## 失敗時と寿命

ステップは作業用の密度行列へコピーして計算し、全要素の実部・虚部と電流の有限性を
スカラーIEEE検査してから切り替えます。数値検査で拒否されたステップは密度・A・電流・時刻を変更しません。
不正なsnapshotも検証を先に行い、復元失敗時は現在の状態を保持します。
モデルの同一性、固定dt・開始時刻など、既存snapshotの互換条件は変えていません。

`close()`は状態の計算処理資源を解放し、繰返し呼べます。閉じた状態のstep、snapshot、restore、
density取得は拒否します。最後の時刻と電流は読み取れます。withかcloseで寿命を明示することを勧めます。
既存コードのためGCによる補助解放も持ち、状態が残る間は計算処理モデルを保持します。
モデルの計算処理キャッシュはPython初期モデルの寿命に連動します。

初期モデルは使用後もデータのみのasdict・pickle・deepcopyを維持します。
プロセス固有のハンドルは移送せず、復元先で新しく準備します。これは状態オブジェクトや
snapshotトークンをpickleで再開する仕様ではありません。

Pythonモデル・状態はスレッド共有不可です。計算処理のレジストリ呼出しは直列化します。
MPIでは従来の`bind_material`による点分散を使えます。

## メモリと計測の読み方

N=nbands²×nkpointsとすると、状態ごとに密度行列を2枚、計32N bytes保持します。
1枚は受理済み、もう1枚は失敗時に戻せる作業領域です。初期モデルごとに、元のPython配列とは別に
計算処理の読み取り用コピーを一つ持ちます。モデル側は概ね104N+16·nbands·nkpoints+8·nkpoints bytesです。
構造体・固定ベクトル・計算ルーチンの作業領域・snapshot一時配列などはこの式に含みません。

常駐メモリが必ず減る設計ではありません。多数の休止状態では作業行列の分だけ増える可能性があり、
コピーの削減とメモリ予算を両方確認します。マシン共通の任意上限は設けず、サイズ計算の整数overflowと
明示allocateの失敗を拒否します。変更していない核の自動作業配列の確保失敗まで回復可能にする保証はありません。

製造データの600ステップ×3回・独立プロセス測定では、明示的コピーの推定量は約9分の1、
速度比は約1.02〜1.03でした。電流・密度は全試行でビット一致。コピー量はソースの明示代入からの推定で、
ハードウェア計測や通信量ではありません。ピークRSSはプロセス全体の最大値で、細かな差をメモリ改善と断定しません。
これは実材料の物理検証や大規模性能の保証ではありません。

## 構築と範囲

通常のwheelは対応した計算処理核を含みます。import時に構築しません。
古い核しかないソース環境では明示的な再構築が必要で、旧stateless版へ暗黙に戻しません。
既存の固定バイナリを残す検証では、別のbuild/install先と
`tools/test_source_materials.py LIBRARY`を使って新しい核を明示できます。
この変更はLDの永続ハンドル化、計算処理TDDFTの複数コンテキスト化、公開C ABIのSBEプラグイン化ではありません。
内部の`sp_sbe_*`はPython接続用で、公開物質ABI1のqueryテーブルとは区別します。

## 単独利用時のパフォーマンスモード

`new_state(...)` またはバッチ応答の入口（LDは `material.respond(...)`、
SBEは `crystal.respond(...)`）に `execution_mode="performance"` を指定します。
既定は `"checked"` です。設定は状態ごとに固定され、更新途中では変更できません。
LDは等方材料と相反なテンソル材料に対応します。結晶SBEは引き続きA/cで駆動し、
電荷電流密度を返します。

Fortranの更新計算は通常モードと共通です。LDは毎ステップの極状態の退避と
有限値検査を省略し、SBEは試行用コピーを作らず密度行列を直接更新します。
異常更新後の自動復元・再試行は保証しません。初期入力・ライブラリの整合性・
配列形状の検査は残ります。明示的な `snapshot()` / `restore()` と出力保存の
検査も残ります。物理状態を復元してもモードは変わりません。TDDFTや外側の
結合ドライバーの検査を無効化する設定ではありません。

同梱例は `--execution-mode performance` に対応しています。新しい条件では
先に通常モードの結果と比較してください。
