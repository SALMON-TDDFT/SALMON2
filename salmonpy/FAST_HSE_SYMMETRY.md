# HSE計算でk点の対称性を使う

[English](FAST_HSE_SYMMETRY.en.md)

対称性で等価なk点をまとめ、計算量を減らせます。結晶の対称性だけでなく、時間発展に与える外場もその対称性を保つ必要があります。

## 対応条件

- 周期系・固定イオン・非スピン分極・CPUのHSE計算が対象です。SOCや分子への対応を意味しません。
- 電子計算のMPI群は1または2ランク、k点分割を使います。
- 時間発展はTaylor法とPT-CN法に対応します。`hse_taylor4`はfactor off／strict／learned、`hse_ptcn`はoff／learnedに対応します。
- 対称性付き計算に対応する計算ライブラリと、同じ入力から準備したGS、k点・対称性情報が必要です。
- 保存／再開では同じMPI分割を使います。再開時に受理済み時間ステップの再計算は行いません。

## Pythonから有効にする

対称性の利用は既定では無効です。次のように指定します。

```python
from salmonpy.fast_hse_mpi import NativeFastHSEBackend

backend = NativeFastHSEBackend(build_record, work_root, allow_symmetry=True)
```

`build_record`は対応する計算ライブラリの構築記録、`work_root`は新しい作業先です。
GSから複数の独立した計算を作る手順は[HSEの複数状態](SHARED_HSE.md)を参照してください。
対称性を無効にした計算への自動切り替えや、別のGSへの自動変換は行いません。

## 外場の方向と対称性

外場はCartesianの3成分A/cを渡します。x、y、z、円偏光を使えますが、保持する各対称操作がすべてのステップのA/cを変えないことが条件です。
例えば、z方向の場にはzを変えないC2z、xy面内の場や円偏光にはxyを変えないmirror-zが候補になります。実際の原子配置と格子にも適合する操作だけを使ってください。
場に合わない対称性は更新前に拒否されます。波形を勝手に投影したり、方向を変更したりしません。
全k点を使う場合に、外場の方向をzに限定するものではありません。

## 入力と保存／再開

`sym.dat`と、入力の`yn_symmetry`で選ぶ対称操作を確認します。`sym.dat`は1操作につき3行、各行4個の実数を持つ形式です。入力値の補完や書き換えは行いません。
セル・原子配置・格子・代表k点の重みは、同じ物質を表す一式として準備してください。一般セルでも、格子と保持する対称操作の適合が必要です。入力単位は原子単位です。

通常混在サンプル`mpi_mixed_native`では、`--hse-symmetry`を明示します。この検査用サンプルは比較用の等価な全k点GSも必要とし、`--hse-reference-bundle FULL_K_BUNDLE`で指定します。`--hse-ranks 1`または`--hse-ranks 2`を使います。
結合計算の保存は、場・LD・SBE・電子状態を同じ完了ステップでまとめます。[保存／再開](CHECKPOINTING.md)を参照してください。

## 結果を確認する

小規模な試験では全k点と縮約k点、独立した状態、保存／再開後の結果を比較しています。任意の実材料について物理的収束を保証するものではありません。使用する物質・波形でk点、格子幅、時間刻みの収束を確認してください。
