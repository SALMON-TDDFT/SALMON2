# W・Se SOC+NLCC 標準選択

2026-10-22のユーザー指定に基づく、このワークスペースの標準擬ポテンシャルです。共通ファイルは親ディレクトリの `W_rps.dat` と `Se_rps.dat` です。停止したMPI2・LSDAメッシュ比較で使用したデータとバイト単位で同一です。

| 元素 | s [Å] | p1/2, p3/2 [Å] | d3/2, d5/2 [Å] | f5/2, f7/2 [Å] | 価電子 | NLCC芯半径 [Å] | 局所l |
|---|---:|---:|---:|---:|---:|---:|---:|
| W（radius2） | 1.59 | 1.01 | 1.38 | 1.59 | 12 | 0.65 | 0 |
| Se | 1.38 | 1.43 | 1.22 | — | 6 | 0.50 | 2 |

## 使用条件

形式は拡張Yabana `KY_SOC_NLCC_V1`、半径はÅ、ポテンシャルはeVです。j分解されたSOCとNLCC芯密度・一次／二次微分を含みます。この形式に対応したreaderと `yn_spinorbit='y'` が必要です。従来KY形式だけを読むSALMON版にはそのまま渡せません。本ブランチには対応readerを統合しています。ヘッダーで旧KY／拡張形式を判別し、拡張形式をSOC無効で渡した場合は拒否します。古い実行ファイルを対応させるには再ビルドが必要です。

現在の検証計算は非共線SOC、LSDA-PZ、電子温度300 Kです。生成器は元の相対論的LDA交換・PZ型相関を継承し、PBE生成データではありません。実行ディレクトリからの相対パスまたは絶対パスを `file_pseudo` に指定してください。

```fortran
&pseudo
 izatom(1)=74, izatom(2)=34,
 file_pseudo(1)='/path/to/SALMON/testsuites/pseudo/W_rps.dat',
 file_pseudo(2)='/path/to/SALMON/testsuites/pseudo/Se_rps.dat'
/
```

## 生成・来歴

同梱の `crps_soc_nlcc.f` と `crps_output.f90` が生成ソース、`W.crps.nml` と `Se.crps.nml` が実際の入力です。c2探索範囲は全チャネル−10.5〜5.0、一意の符号変化区間だけを採用しています。NLCC一次微分の最初の正半径点にあった符号誤りは、このソースとデータでは修正済みです。過去の原本・生成ログ・旧データはwork配下に保存しています。

```sh
gfortran -std=legacy -O0 -fcheck=all -fbacktrace -Wno-align-commons \
  crps_output.f90 crps_soc_nlcc.f -o crps
# 元データを上書きしない空の作業ディレクトリで、入力を渡して実行する。
/path/to/crps /path/to/W.crps.nml
```

正確なSHA256、元ファイル、全チャネル、格子・単位は `manifest.json` に記録しています。

## 検証範囲

有限値・形式・価電子数・指定半径・原点近傍のポテンシャル／擬波動関数の形状・NLCC微分整合性は確認済みです。「標準」はユーザーが選択した計算基準を意味します。散乱／ghost状態の網羅検証、固体の精度、メッシュ収束、5 fs電流比較の合格を意味しません。旧MPI2メッシュ比較はSOCゼロ射影子の適用側添字不整合が見つかりユーザー承認で停止しました。旧結果は収束判定に使用しません。readerの本体試験451で不具合を再現し、対応表作成と同じ除外条件で修正しています。

## 生成プログラムの共通配置

生成プログラムは `utility/crps_soc_nlcc/` にも保存しています。ビルド・再生成手順は同ディレクトリのREADME、再生成したW・Seが標準データとバイト単位で一致した結果はprovenance.jsonを参照してください。


## 入力制御の自動化（2026-10-22）

SALMONでは拡張KYのヘッダーを検出すると、省略した`spin`と`yn_spinorbit`を
`noncollinear`と`y`へ解決します。`spin='noncollinear'`または`yn_spinorbit='y'`の
片方だけの指定でも他方を補完します。旧KYで両方省略した場合は従来どおり
unpolarized/SOCなしです。明示的なSOC無効化や不整合なスピン指定は拒否し、
自動的なスカラー平均はしません。解決済みの値をvariables.logへ記録します。
他形式のSOC情報の自動検出はこの変更の対象外です。
拡張KYの`lloc_ps`指定も不要です。ファイル内に格納された局所ポテンシャルを使います。
旧KYの局所参照チャネルは物理的な選択なので、この省略規則は適用しません。

生成器の`&crps`では、以下の制御指定を省略できます。

- `Lmax`: 先頭から連続する3/5/7チャネルの半径リストから1/2/3を導出。
  部分・疎なリストを上書きする場合はLmaxを明示してください。
- `NA`: 有効なPtoAの最大参照軌道番号。占有数合計と核電荷の検査は維持。
- `lloc`: 解決後のLmax。W標準のlloc=0は物理的選択なので明示を維持。
- `output_file`: 入力namelistの拡張子を除いたbasenameに`_soc_nlcc_rps.dat`を追加。
- `c2lo`: 既存の探索下限-10.5。標準W/Seの上限c2hi=5は引き続き明示。

明示した値は上書きせず、引数なしの従来Au初期値も維持します。
元素、占有数、参照軌道、半径、NLCC芯半径、必要な局所チャネルは物理入力として残します。
W/Seの省略入力と明示入力は、同じ生成器でbyte一致し、配布済み標準表とも数値照合します。
