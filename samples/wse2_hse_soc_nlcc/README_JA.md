# 単層WSe2・直交Conventional Cell：HSE06＋SOC＋NLCC

固定核・非DC・CPUでの計算準備パッケージ。数値収束を確認した結果ではない。
構造は単層1H相のW2Se4直交6原子セルで、バルク2Hの2層セルではない。
a=3.29 Å、b=√3a、Se面はW面から上下1.67 Å。参考文献・k点換算はLITERATURE_JA.md。

## 入力と対称性

- nelec=nstate=48、占有1のスピノル。PBE19 W/Seの完全相対論的・NLCCありの原本を使用。
- GSは固定構造でPBE予備SCFからHSE06へ切替、最終密度残差1e-8。600反復での収束は保証しない。
- HSE omega=.11 bohr^-1、混成率.25。全入力は原子単位。
- 各ケースにgs、gs-x、rt-x、rt-y。x RTはgs-x、y RTはgsの再開データを読む。異なるk点・格子・セル・対称群のGSを共有しない。
- GSのsym.datはE、Mx、Mz、C2yと各々の直交胞心並進(.5,.5,0)：8操作。これは六方晶D3h全12操作ではない。120度回転は直交シミュレーション格子を保たず、この格子では使えない。
- rt-x/gs-xはE、Mzと並進の4操作。偏光xはOFFでyn_symmetry='nyy'。
- rt-yはy偏光を保つ8操作、偏光yはOFFでyn_symmetry='yny'。gsはyyyでも同じ操作集合となる。
- スピンは軸性ベクトルとして変換し、非対角スピン密度を含む。時間反転による追加削減は使わない。
- 空間SR近似・学習ACE・FFT orbit再利用・q削減を使わず、Taylor4+ACEでRTを計算。

## 収束系列と判定

基準候補はk24x18、実空間18×32×144、Lz=25.2 Å（原子面間の空隙21.86 Å）。
格子間隔は約.183/.178/.175 Å。特にWに対する格子収束を未確認なので、生産条件とは呼ばない。

1. 実空間格子：基準、24×42×192、28×48×216を比較。全エネルギー1 meV/atom以内、低エネルギー応答とピーク位置も比較。採用格子が変わったら、その格子を固定してk系列を再生成する。
2. 真空：Lz=25.2、31.5、37.8 Å。z格子間隔を一定に保ち、面内シート応答Lz*(epsilon−1)で比較。
3. k：12×8、18×12、24×18、36×24、48×30、60×36。少なくとも最後の2段階で応答の最大相対差2%以内・各対象ピークの変化.02 eV以内を候補基準とする。必要ならさらに増やす。
4. RT：dt=.00025 fsと半分、インパルス1e-4 auと半分、60 fsと120 fs。元のGSを各ケースで独立に収束させる。
5. x/y応答を比較して数値異方性を調べる。直交k点・格子は厳密な3回回転対称性を持たないので、x/y一致を前提に平均しない。
6. GSの予備SCFあり/なしも比較する。数値・磁化・占有状態・エネルギーを調べて別解へ収束していないか確認。

60 fsの有限時間尺度h/Tは約.069 eV、120 fsでは.034 eV。出力.01 eV刻みは実際の分解能ではない。
SALMONの既定多項式時間窓を揃える。0.02 eV精度のピーク判定には、時間窓も十分長いことを別に確認する。
A/BのSOC分裂と励起子の定量性は同じ問題ではなく、HSE06 RTをGW–BSEや実測の励起子位置の保証としない。

## 実行と保護

manifest.jsonとSHA256SUMSに全入力・原本の出自を保存。preflight.pyは計算を実行しない。

```sh
python3 preflight.py
sha256sum --check SHA256SUMS
```

job.shは富岳の新規領域を絶対参照し、各MPI rankに1ノード・48OMPを配置する準備値。
密度タイルとスピノル配列のメモリ見積りはcase.json。24配列相当の保守的な計画値であり、実測ではない。
最初の実計算でRSSと所要時間を記録して配置を調整する。rank数は既約k点数以下である必要がある。
実行前に新binaryのSHA/source commitをbinary.jsonへ固定する。既存Si511 binaryへの差替えは禁止。

ジョブは自動投入しない。gsまたはgs-xがcheck_run.pyに合格してから対応するRTを投入する。
非収束GS・時間切れGSは再開ファイルが存在しても使わない。SOC checkpoint継続は未対応なので途中打切りを再開しない。
run.lockやsubmission記録を確認して重複投入を避ける。ログインノードでSALMONを動作確認しない。

面内2D応答はepsilon_cellとLz*(epsilon_cell−1)を併記する。SIのシート分極率はepsilon0*Lz*(epsilon−1)。
任意の厚さdで誘電率へ換算する場合はepsilon_layer=1+(Lz/d)*(epsilon_cell−1)とdを明記する。
この式を面外成分に流用しない。compare_spectra.pyは原子単位の13列response表から面内シート量を比較する。

## スピノルpair FFTの規約対応版（2026-10-19）

通常は最適化スイッチを省略する。`exx_k_algorithm` は既定 `auto` で、
SOCでは性能確認済みになるまで従来経路を使う。比較時だけ `reference` または
`pair` を指定する。旧 `yn_exx_spinor_pair_fft` は互換入力として残る。
`variables.log` と `EXX_K_ALGORITHM` で解決値・選択理由を確認する。
旧実験版の環境変数 `SALMON_EXX_FFT_ORBITS=pair` は、この修正版では読まない。
CPU・全q点・既存SOC HSE06条件が必要。SU(2)展開を維持し、実空間点対称性での
FFT削減は行わない。RTの偏光方向に対応する対称性は従来どおりOFF。

富岳に配置済みの037c301は旧選択方法の版であり、今回の修正版とは区別する。
今回の規約修正では既存バイナリ・ジョブの入力・起動先を変更していない。
