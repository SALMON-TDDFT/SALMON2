# Si の z 偏光に使う対称操作

`sym.dat` は、立方慣用胞 Si8（原点に Si、もう一方の副格子が
(1/4,1/4,1/4)）に対する、z 方向を変えない 32 個の空間群操作です。
xy 面の符号反転・交換からなる 8 点群操作と、必要な分数並進に加え、
4 個の FCC センタリング並進を含めています。

8 個の代表操作だけでは慣用胞の整数並進を法として閉じません。
例えば x 反転と (1/4,1/4,1/4) 並進の合成操作を二度適用すると、
(0,1/2,1/2) 並進になります。波動関数の占有部分空間が初めから
FCC 並進対称性を厳密に満たすとは仮定せず、32 操作の閉じた群を使います。
センタリング並進は k を動かさないため、下記の既約 k 点数は変わりません。
交換計算での再構成コストは別途計測が必要です。
入力と同じ作業ディレクトリへコピーし、`yn_symmetry='yyn'` を指定します。
原子の原点・胞・構造を変えた場合は、そのまま流用しないでください。

標準の半格子シフトを持つ等間隔 k 格子では、4³ は 12 点、16³ は
576 点になります。一般位置の軌道は 8 点ですが、kx=±ky の点では
4 点になるため、有限格子の削減率は厳密な 1/8 ではありません。
ここでは時間反転や z を反転する操作は加えていません。これらは有限の
z 向きベクトルポテンシャルを不変にしないためです。

固定 α の TDCDFT（`tdcdft_screening='none'`）と HSE06 の実時間計算では、
読み込んで選別した実際の群が z 向きの場を保つことを初期化時に検査します。
HSE06/TDCDFT では、操作がシミュレーション胞の整数並進を法として閉じ、
重複を含まないことも検査します。
TDCDFT では両方のパルスの偏光を z に限定し、ファイルからの外場入力と
時間依存遮蔽は、この対応の範囲外として拒否します。

軽量検証:

```sh
python3 samples/exercise_si_symmetry/test_symmetry.py
python3 samples/exercise_si_symmetry/test_checkpoint.py
```

原子配置の写像、群の閉包性、正確な既約 k 点数、および実際の Fortran 初期化の
検査（正常な群の受理、場を反転する群と閉じていない 8 操作の拒否）を確認します。

実時間再開では `symmetry_restart.bin` に k 点・重み・両座標系の群を保存し、
対称性の有無や群を途中で変更した再開を拒否します。対称性なしの旧チェックポイントは
この追加ファイルなしで再開できます。原子位置と元素種の置換も初期化時に検査します。
